ingredients:
  - { qte: 4, unite: tranche, nom: "jarret de veau avec os, de 4 cm d'épaisseur" }
  - { qte: 40, unite: g, nom: "farine" }
  - { qte: 40, unite: g, nom: "beurre" }
  - { qte: 2, unite: "c. à soupe", nom: "huile d'olive" }
  - { qte: 1, unite: "", nom: "oignon", groupe: "Soffritto" }
  - { qte: 1, unite: "", nom: "carotte", groupe: "Soffritto" }
  - { qte: 1, unite: branche, nom: "céleri", groupe: "Soffritto" }
  - { qte: 20, unite: cl, nom: "vin blanc sec" }
  - { qte: 40, unite: cl, nom: "fond blanc de veau" }
  - { qte: 400, unite: g, nom: "tomates pelées" }
  - { qte: 1, unite: "", nom: "zeste de citron non traité", groupe: "Gremolata" }

etapes:
  - "Entailler le pourtour de chaque tranche pour qu'elle ne se recroqueville pas. Saler, poivrer, fariner légèrement."
  - "Saisir les tranches dans le beurre et l'huile chauds, 4 minutes par face. Réserver."
  - "Faire revenir oignon, carotte et céleri en petits dés 8 minutes. Déglacer au vin blanc, réduire de moitié."
  - "Ajouter les tomates écrasées et le fond chaud. Remettre les tranches debout, pour garder la moelle dans l'os. Le liquide doit arriver aux trois quarts."
  - "Couvrir et cuire 1 h 30 à feu très doux, en arrosant. La viande doit se détacher de l'os."
  - "Mélanger les ingrédients de la gremolata, en parsemer le plat à la sortie du feu. Servir avec un risotto à la milanaise."
---

Braisé de tranches de jarret à l'italienne. La farine sur la viande crue et le fond de veau clair
le rapprochent du Marengo ; la gremolata finale, fraîche et acide, fait contrepoint à la richesse
de la moelle.
