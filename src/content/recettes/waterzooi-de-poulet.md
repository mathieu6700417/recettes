  - { qte: 2, unite: branche, nom: "céleri" }

  - { qte: 1, unite: "", nom: "bouquet garni" }

etapes:

Le waterzooi gantois prolonge la blanquette : même liaison crème et jaune, mais la volaille est
pochée au lieu d'être mijotée, et le bouillon est lié sans roux. C'est un plat entre soupe et ragoût.
