ingredients:
  - { qte: 1, unite: "", nom: "coq (ou poulet fermier) de 1,8 kg, découpé en 8 morceaux" }
  - { qte: 75, unite: cl, nom: "vin rouge", groupe: "Marinade" }
  - { qte: 1, unite: "", nom: "oignon émincé", groupe: "Marinade" }
  - { qte: 1, unite: "", nom: "carotte en rondelles", groupe: "Marinade" }
  - { qte: 1, unite: "", nom: "bouquet garni", groupe: "Marinade" }
  - { qte: 150, unite: g, nom: "lardons fumés", groupe: "Garniture" }
  - { qte: 16, unite: "", nom: "petits oignons grelots", groupe: "Garniture" }
  - { qte: 250, unite: g, nom: "champignons de Paris", groupe: "Garniture" }
  - { qte: 30, unite: g, nom: "beurre" }
  - { qte: 2, unite: "c. à soupe", nom: "farine" }
  - { qte: 4, unite: cl, nom: "cognac" }
  - { qte: 2, unite: gousse, nom: "ail" }
  - { qte: 10, unite: cl, nom: "sang de volaille mêlé d'une cuillère de vinaigre (facultatif)", groupe: "Liaison" }
  - { qte: null, unite: "", nom: "sel, poivre" }
etapes:
  - "Mariner le coq avec les ingrédients de la marinade 12 h au froid."
  - "Égoutter, sécher les morceaux ; garder vin et légumes séparément."
  - "Dorer les lardons dans une cocotte, les réserver. Colorer les morceaux de coq dans la graisse et le beurre, 4 minutes par face."
  - "Flamber au cognac. Ajouter les légumes de marinade et l'ail, saupoudrer de farine et remuer 2 minutes."
  - "Verser le vin filtré, porter à frémissement, couvrir et cuire 1 h 15 à feu doux."
  - "Faire dorer séparément les petits oignons et les champignons, les ajouter pour les 20 dernières minutes avec les lardons."
  - "Si l'on utilise le sang, retirer la cocotte du feu, le délayer avec 2 louches de sauce, verser en remuant et chauffer 2 minutes sans bouillir. Servir avec des pâtes fraîches ou des pommes vapeur."
---

Le coq au vin garde l'ossature du bourguignon (vin, lardons, oignons, champignons) mais la volaille
cuit plus vite, et la liaison au sang, dans la tradition, remplace en partie le singer.
