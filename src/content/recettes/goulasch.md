  slug: ragout
  mutation: "bœuf et oignons mijotés avec beaucoup de paprika"
bases:
  - slug: fond-brun
    mutation: "eau ou bouillon, sans vin, parfumé au paprika"
ingredients:
  - { qte: 1.2, unite: kg, nom: "paleron de bœuf, en cubes de 3 cm" }
  - { qte: 800, unite: g, nom: "oignons émincés" }
  - { qte: 50, unite: g, nom: "saindoux (ou huile)" }
  - { qte: 3, unite: "c. à soupe", nom: "paprika doux" }
  - { qte: 1, unite: "c. à café", nom: "paprika fort (facultatif)" }
  - { qte: 1, unite: "c. à café", nom: "graines de cumin" }
  - { qte: 2, unite: gousse, nom: "ail" }
  - { qte: 2, unite: "", nom: "poivrons rouges" }
  - { qte: 400, unite: g, nom: "tomates pelées" }
  - { qte: 80, unite: cl, nom: "bouillon de bœuf ou eau" }
  - { qte: 600, unite: g, nom: "pommes de terre" }
  - { qte: 1, unite: "", nom: "feuille de laurier" }
  - { qte: null, unite: "", nom: "sel, crème aigre pour servir" }
etapes:
  - "Faire fondre les oignons dans le saindoux 20 minutes à feu moyen-doux, jusqu'à ce qu'ils soient dorés."
  - "Ajouter le bœuf, le saisir 5 minutes en remuant. Retirer la cocotte du feu, ajouter le paprika, le cumin et l'ail, remuer 30 secondes (le paprika brûle vite et devient amer)."
  - "Ajouter les tomates, le laurier, le bouillon pour couvrir aux deux tiers. Saler. Porter à frémissement, couvrir."
  - "Cuire 1 h 30 à feu doux. Ajouter les poivrons en lanières, puis les pommes de terre en cubes 30 minutes avant la fin."
  - "Poursuivre jusqu'à ce que la viande soit tendre et la sauce épaisse sans farine. Servir avec une cuillère de crème aigre."
---

Cousin hongrois du ragoût : pas de vin, pas de farine, la sauce est liée par les oignons fondus et
les pommes de terre. Le paprika, toujours ajouté hors du feu, en fait la signature.
