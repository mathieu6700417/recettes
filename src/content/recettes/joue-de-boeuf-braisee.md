---
titre: Joue de bœuf braisée
origine: FR
portions: 4
preparation: 25
cuisson: 210
difficulte: facile
cuisson_technique:
  slug: braiser
  mutation: "joues entières saisies, braisées au four"
bases:
  - slug: fond-brun
    mutation: "fond brun réduit en jus nappant"
ingredients:
  - { qte: 4, unite: "", nom: "joues de bœuf parées (environ 250 g chacune)" }
  - { qte: 2, unite: "c. à soupe", nom: "huile" }
  - { qte: 1, unite: "", nom: "oignon" }
  - { qte: 2, unite: "", nom: "carottes" }
  - { qte: 2, unite: gousse, nom: "ail" }
  - { qte: 1, unite: "c. à soupe", nom: "concentré de tomate" }
  - { qte: 50, unite: cl, nom: "vin rouge" }
  - { qte: 30, unite: cl, nom: "fond brun" }
  - { qte: 1, unite: "", nom: "bouquet garni" }
  - { qte: 20, unite: g, nom: "beurre froid, pour monter la sauce" }
  - { qte: null, unite: "", nom: "sel, poivre" }
etapes:
  - "Chauffer le four à 150 °C. Saler et poivrer les joues, bien les sécher."
  - "Dans une cocotte, saisir les joues dans l'huile très chaude, 4 minutes par face. Réserver."
  - "Faire revenir oignon et carottes en dés 5 minutes, ajouter l'ail et le concentré de tomate, cuire 2 minutes."
  - "Déglacer au vin rouge, réduire de moitié, verser le fond brun, remettre les joues : le liquide doit atteindre à peine mi-hauteur. Ajouter le bouquet garni."
  - "Couvrir et cuire au four 3 h à 3 h 15, en retournant les joues à mi-cuisson. Elles doivent se couper à la cuillère."
  - "Réserver la viande au chaud, passer et réduire la sauce de moitié, hors du feu monter au beurre froid. Napper et servir avec une purée."
---

Braisé pur : une pièce entière, peu de liquide, et une sauce obtenue par réduction du jus de
cuisson. Il se distingue du bourguignon par l'absence de coupe en cubes et de singer.
