ingredients:
  - { qte: 1.5, unite: kg, nom: "paleron ou macreuse de bœuf, en cubes de 5 cm" }
  - { qte: 1, unite: kg, nom: "oignons émincés" }
  - { qte: 50, unite: g, nom: "beurre" }
  - { qte: 50, unite: cl, nom: "bière brune d'abbaye" }
  - { qte: 25, unite: cl, nom: "bouillon de bœuf" }
  - { qte: 4, unite: tranche, nom: "pain d'épices" }
  - { qte: 2, unite: "c. à soupe", nom: "moutarde forte" }
  - { qte: 2, unite: "c. à soupe", nom: "vinaigre de cidre" }
  - { qte: 1, unite: "c. à soupe", nom: "cassonade" }
  - { qte: 1, unite: "", nom: "bouquet garni (thym, laurier)" }
  - { qte: null, unite: "", nom: "sel, poivre" }
etapes:
  - "Saisir les cubes de bœuf dans 30 g de beurre, en plusieurs fois, jusqu'à belle coloration. Réserver."
  - "Faire fondre doucement les oignons dans le reste du beurre 15 minutes, avec la cassonade, jusqu'à ce qu'ils soient dorés et très tendres."
  - "Alterner viande et oignons dans la cocotte, saler, poivrer. Verser la bière et le bouillon pour couvrir aux deux tiers."
  - "Tartiner le pain d'épices de moutarde et le poser sur la viande, face moutardée dessous. Ajouter le bouquet garni."
  - "Porter à frémissement, couvrir et cuire 2 h à 2 h 15 à feu très doux ou au four à 150 °C, jusqu'à ce que la viande soit fondante."
  - "Ajouter le vinaigre en fin de cuisson, remuer pour dissoudre le pain d'épices qui lie la sauce, rectifier l'assaisonnement. Servir avec des frites ou des pommes vapeur."
---

Même squelette que le bourguignon, adapté à la Flandre : bière brune au lieu du vin, oignons
nombreux, et pain d'épices à la place de la farine pour lier. Le vinaigre final compense le sucre.
