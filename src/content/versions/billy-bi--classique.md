statut: relu-agent
portions: 4
temps: { preparation: 25, cuisson: 25 }
difficulte: moyen
ingredients:
  - { ingredient: moule, qte: 2, unite: kg, precision: "grattées et rincées" }
  - { ingredient: echalote, qte: 2, unite: "", precision: "ciselées" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "émincé" }
  - { ingredient: beurre, qte: 30, unite: g }
  - { ingredient: vin-blanc, qte: 30, unite: cl, precision: "sec" }
  - { ingredient: persil, qte: 4, unite: branche }
  - { ingredient: thym, qte: 1, unite: branche }
  - { ingredient: laurier, qte: 1, unite: "" }
  - { ingredient: creme-liquide, qte: 40, unite: cl }
  - { ingredient: jaune-d-oeuf, qte: 2, unite: "", groupe: "Liaison" }
  - { ingredient: safran, qte: 1, unite: pincée, precision: "facultatif" }
  - { ingredient: poivre, qte: null, unite: "" }
  - { ingredient: sel, qte: null, unite: "", precision: "seulement si nécessaire" }
etapes:
  - "Gratter les moules, retirer les byssus et les rincer à l'eau froide. Jeter celles qui sont cassées ou qui restent ouvertes quand on les tapote."
  - "Dans une grande cocotte, faire suer l'échalote et l'oignon dans le beurre 3 minutes sans coloration."
  - "Ajouter le vin blanc, le persil, le thym et le laurier, porter à ébullition, puis ajouter les moules. Couvrir et cuire à feu vif 5 à 6 minutes en secouant la cocotte, jusqu'à ce qu'elles soient toutes ouvertes."
  - "Égoutter les moules au-dessus d'un saladier pour recueillir tout le jus. Les décortiquer et réserver quelques-unes pour le service (le reste se garde pour une salade)."
  - "Filtrer le jus à travers un linge fin ou un filtre à café, en laissant le sable au fond. Le verser dans une casserole avec le safran et le réduire d'un tiers à feu moyen, environ 5 minutes."
  - "Ajouter 30 cl de crème et laisser frémir 5 minutes. Poivrer ; ne saler qu'après avoir goûté, le jus de moules est déjà salé."
  - "Mélanger les jaunes avec le reste de la crème. Y verser une louche de soupe chaude en fouettant, puis reverser le tout dans la casserole hors du feu."
  - "Remettre sur feu très doux 2 minutes en remuant, sans laisser bouillir, jusqu'à ce que la soupe nappe légèrement la cuillère. Servir aussitôt avec quelques moules décortiquées."
---

Se déguste chaude ou bien froide. Une fois liée, la soupe ne se réchauffe pas à ébullition.
