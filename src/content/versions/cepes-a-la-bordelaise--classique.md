---
preparation: cepes-a-la-bordelaise
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 15, cuisson: 15 }
difficulte: facile
ingredients:
  - { ingredient: cepe, qte: 800, unite: g, precision: "frais, nettoyés, en tranches de 1 cm" }
  - { ingredient: huile-neutre, qte: 3, unite: c. à soupe }
  - { ingredient: beurre, qte: 30, unite: g }
  - { ingredient: echalote, qte: 2, unite: "", precision: "finement hachées" }
  - { ingredient: ail, qte: 2, unite: gousse, precision: "hachées" }
  - { ingredient: persil-plat, qte: 4, unite: branche, precision: "ciselé" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Essuyer les cèpes avec un linge humide et les couper en tranches épaisses."
  - "Chauffer la moitié de l'huile dans une grande poêle à feu vif. Y saisir la moitié des cèpes 5 à 6 minutes, en les retournant, jusqu'à ce qu'ils soient dorés. Les réserver et recommencer avec le reste."
  - "Remettre tous les cèpes dans la poêle, ajouter le beurre et l'échalote, et cuire 2 minutes à feu moyen."
  - "Ajouter l'ail et cuire 1 minute de plus, sans le laisser brunir."
  - "Saler et poivrer, hors du feu parsemer de persil. Servir aussitôt."
---

Servir en accompagnement d'un œuf au plat, de pommes de terre sautées ou sur une tranche de pain grillé.
