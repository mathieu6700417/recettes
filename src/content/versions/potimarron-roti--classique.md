---
preparation: potimarron-roti
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 10, cuisson: 35 }
difficulte: facile
ingredients:
  - { ingredient: potimarron, qte: 1.2, unite: kg, precision: "non épluché, en quartiers de 3 à 4 cm" }
  - { ingredient: huile-d-olive, qte: 4, unite: "c. à soupe" }
  - { ingredient: sauge, qte: 8, unite: feuille, precision: "ou 3 branches de thym" }
  - { ingredient: ail, qte: 2, unite: gousse, precision: "non épluchées, écrasées" }
  - { ingredient: graine-de-courge, qte: 2, unite: "c. à soupe", precision: "facultatif" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Préchauffer le four à 200 °C (chaleur tournante si possible)."
  - "Laver le potimarron, le couper en deux, retirer les graines et les filaments. Couper chaque moitié en quartiers de 3 à 4 cm de large, sans éplucher."
  - "Mélanger les quartiers dans un grand plat avec l'huile d'olive, du sel et du poivre, en les enrobant bien. Les ranger sur une plaque, côté peau dessous, sans qu'ils se chevauchent. Glisser l'ail entre les quartiers."
  - "Enfourner 20 minutes, retourner les quartiers, puis poursuivre 10 minutes."
  - "Ajouter la sauge (ou le thym) et les graines de courge, et cuire encore 5 minutes : la chair doit être tendre et dorée sur les bords."
  - "Servir tiède, avec un filet d'huile d'olive crue si l'on veut."
---

Les quartiers rôtis se mangent en accompagnement d'une viande rôtie, ou en plat avec une salade verte et du fromage de chèvre.
