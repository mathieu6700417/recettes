ingredients:
  - { ingredient: boeuf-a-braiser, qte: 1.5, unite: kg, precision: "paleron ou macreuse, en cubes de 5 cm" }
  - { ingredient: oignon, qte: 1, unite: kg, precision: "émincés" }
  - { ingredient: beurre, qte: 60, unite: g }
  - { ingredient: biere-brune, qte: 50, unite: cl, precision: "d'abbaye" }
  - { preparation: fond-brun, qte: 25, unite: cl, precision: "ou bouillon de bœuf" }
  - { ingredient: pain-d-epices, qte: 4, unite: tranche }
  - { ingredient: moutarde-forte, qte: 2, unite: c. à soupe }
  - { ingredient: vinaigre-de-cidre, qte: 2, unite: c. à soupe }
  - { ingredient: cassonade, qte: 1, unite: c. à soupe }
  - { ingredient: thym, qte: 1, unite: branche, precision: "bouquet garni" }
  - { ingredient: laurier, qte: 1, unite: "", precision: "bouquet garni" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Saisir les cubes de bœuf dans 30 g de beurre, en plusieurs fois, jusqu'à belle coloration. Réserver."
  - "Faire fondre doucement les oignons dans le reste du beurre 30 minutes, avec la cassonade, jusqu'à ce qu'ils soient dorés et très tendres."
  - "Alterner viande et oignons dans la cocotte, saler, poivrer. Verser la bière et le fond brun pour couvrir aux deux tiers."
  - "Tartiner le pain d'épices de moutarde et le poser sur la viande, face moutardée dessous. Ajouter le bouquet garni."
  - "Porter à frémissement, couvrir et cuire 2 h à 2 h 15 à feu très doux ou au four à 150 °C, jusqu'à ce que la viande soit fondante."
  - "Ajouter le vinaigre en fin de cuisson, remuer pour dissoudre le pain d'épices qui lie la sauce, rectifier l'assaisonnement. Servir avec des frites ou des pommes vapeur."
