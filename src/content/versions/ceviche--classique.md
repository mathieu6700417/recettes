difficulte: facile
ingredients:
  - { ingredient: poisson-blanc, qte: 600, unite: g, precision: "filet très frais, sans arêtes, congelé 24 h à −20 °C puis décongelé" }
  - { ingredient: citron-vert, qte: 8, unite: "", precision: "le jus, environ 20 cl" }
  - { ingredient: oignon-rouge, qte: 1, unite: "", precision: "émincé très finement" }
  - { ingredient: piment-frais, qte: 1, unite: "", precision: "épépiné et haché, à ajuster" }
  - { ingredient: ail, qte: 1, unite: gousse, precision: "écrasée" }
  - { ingredient: coriandre-fraiche, qte: 1, unite: botte, precision: "ciselée" }
  - { ingredient: patate-douce, qte: 2, unite: "", precision: "cuites à l'eau et coupées en rondelles, pour servir" }
  - { ingredient: mais, qte: 200, unite: g, precision: "en grains cuits, pour servir" }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Congeler le poisson 24 h à −20 °C avant de le décongeler au réfrigérateur : cela élimine les parasites éventuels. Le garder à moins de 4 °C."
  - "Rincer l'oignon émincé à l'eau froide 5 minutes pour adoucir, puis l'égoutter."
  - "Couper le poisson en dés de 2 cm. Saler légèrement."
  - "Mélanger dans un saladier froid le jus de citron vert, l'ail, le piment et du sel."
  - "Verser sur le poisson, ajouter l'oignon et laisser mariner au frais 10 à 15 minutes, jusqu'à ce que la chair soit opaque en surface mais encore nacrée au cœur."
  - "Ajouter la coriandre, goûter, rectifier le sel et le piquant."
  - "Servir tout de suite avec la marinade, accompagné de rondelles de patate douce et de maïs."
---

Sécurité : poisson cru, à consommer le jour même. Éviter ce plat pour les femmes enceintes et les
personnes fragiles.
