ingredients:
  - { ingredient: chou-rouge, qte: 1, unite: "", precision: "environ 1 kg, ciselé finement, sans le trognon" }
  - { ingredient: pomme-granny-smith, qte: 3, unite: "", precision: "pelées, en dés" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "émincé" }
  - { ingredient: beurre, qte: 30, unite: g }
  - { ingredient: vinaigre-de-cidre, qte: 6, unite: c. à soupe }
  - { ingredient: cassonade, qte: 2, unite: c. à soupe }
  - { ingredient: clou-de-girofle, qte: 2, unite: "" }
  - { ingredient: laurier, qte: 2, unite: "" }
  - { ingredient: eau, qte: 10, unite: cl }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Faire fondre le beurre dans une cocotte et y faire suer l'oignon 5 minutes sans coloration."
  - "Ajouter le chou ciselé et le vinaigre, mélanger, puis laisser réduire 5 minutes."
  - "Ajouter les pommes, la cassonade, les clous de girofle, le laurier, l'eau, du sel et du poivre."
  - "Couvrir et cuire 1 heure à feu doux, en remuant de temps en temps, jusqu'à ce que le chou soit très tendre."
  - "Goûter et rectifier avec un peu de vinaigre ou de cassonade. Retirer le laurier et les clous avant de servir."
---

Le chou rouge se réchauffe très bien et gagne en goût le lendemain.
