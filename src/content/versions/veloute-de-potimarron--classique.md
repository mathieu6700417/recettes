---
preparation: veloute-de-potimarron
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 15, cuisson: 30 }
difficulte: facile
ingredients:
  - { ingredient: potimarron, qte: 1, unite: kg, precision: "non épluché, en morceaux de 3 cm" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "émincé" }
  - { ingredient: beurre, qte: 20, unite: g }
  - { preparation: fond-de-legumes, qte: 0.75, unite: l, precision: "chaud" }
  - { ingredient: creme-liquide, qte: 10, unite: cl }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Laver le potimarron, le couper en deux, retirer les graines et les filaments avec une cuillère. Le couper en morceaux de 3 cm sans l'éplucher."
  - "Faire fondre le beurre dans une grande casserole à feu moyen. Y faire suer l'oignon 5 minutes, sans coloration."
  - "Ajouter le potimarron et remuer 2 minutes, puis verser le fond de légumes chaud : il doit arriver presque à hauteur des morceaux."
  - "Porter à frémissement, couvrir et laisser mijoter à feu doux 20 à 25 minutes, jusqu'à ce qu'un morceau s'écrase sans résistance."
  - "Mixer finement au mixeur plongeant, directement dans la casserole, 2 à 3 minutes, jusqu'à obtenir une texture bien lisse."
  - "Ajouter la crème et la muscade, réchauffer sans bouillir. Si le velouté est trop épais, l'allonger d'un peu de fond chaud ou d'eau. Saler et poivrer."
  - "Servir aussitôt, avec un filet de crème ou quelques graines de courge grillées si l'on veut."
---

Le velouté se garde 3 jours au réfrigérateur et se congèle bien avant l'ajout de la crème.
