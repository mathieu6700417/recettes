ingredients:
  - { ingredient: farine, qte: 250, unite: g, groupe: "Pâte" }
  - { ingredient: beurre, qte: 125, unite: g, precision: froid, groupe: "Pâte" }
  - { ingredient: eau, qte: 50, unite: ml, precision: froide, groupe: "Pâte" }
  - { ingredient: sucre-en-poudre, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: "pincée", groupe: "Pâte" }
  - { ingredient: pomme-golden, qte: 1, unite: kg, groupe: "Garniture" }
  - { ingredient: sucre-en-poudre, qte: 60, unite: g, groupe: "Garniture" }
  - { ingredient: beurre, qte: 30, unite: g, groupe: "Garniture" }
  - { ingredient: confiture-d-abricot, qte: 3, unite: c. à soupe, groupe: "Finition" }
  - { ingredient: eau, qte: 1, unite: c. à soupe, groupe: "Finition" }
etapes:
  - "Pâte : sabler la farine, le sel, le sucre et le beurre froid en dés, ajouter l'eau et rassembler sans pétrir. Filmer et laisser reposer 1 heure au frais."
  - "Préchauffer le four à 180 °C. Abaisser la pâte à 3 mm, foncer un moule de 28 cm, piquer le fond et le réserver au frais."
  - "Peler et évider les pommes. En couper 2 en petits dés et les répartir sur le fond. Émincer les autres en lamelles de 3 mm."
  - "Disposer les lamelles en rosace serrée, saupoudrer de sucre et parsemer de petits morceaux de beurre."
  - "Cuire 40 minutes à 180 °C, jusqu'à ce que les pommes soient dorées et la pâte bien colorée."
  - "Chauffer la confiture d'abricot avec l'eau, passer et badigeonner la tarte tiède au pinceau."
