---
preparation: frites-de-patate-douce
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 15, cuisson: 30 }
difficulte: facile
ingredients:
  - { ingredient: patate-douce, qte: 800, unite: g, precision: "en bâtonnets de 1 cm" }
  - { ingredient: fecule-de-mais, qte: 2, unite: "c. à soupe" }
  - { ingredient: huile-neutre, qte: 3, unite: "c. à soupe" }
  - { ingredient: paprika-fume, qte: 1, unite: "c. à café" }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Préchauffer le four à 220 °C (chaleur tournante si possible) avec une plaque à l'intérieur."
  - "Éplucher les patates douces et les couper en bâtonnets réguliers de 1 cm de section. Bien les sécher dans un torchon."
  - "Dans un grand saladier, les mélanger avec la fécule de maïs jusqu'à ce qu'elles soient uniformément poudrées, puis ajouter l'huile et le paprika fumé et mélanger de nouveau."
  - "Étaler les frites en une seule couche sur la plaque chaude, sans qu'elles se touchent (utiliser deux plaques si nécessaire)."
  - "Enfourner 25 à 30 minutes, en les retournant à mi-cuisson, jusqu'à ce qu'elles soient dorées et croustillantes sur les bords."
  - "Saler dès la sortie du four et servir immédiatement."
---

Pour la friture : plonger les bâtonnets enrobés de fécule 4 minutes dans une huile à 160 °C, les égoutter,
puis les frire de nouveau 2 minutes à 180 °C.
