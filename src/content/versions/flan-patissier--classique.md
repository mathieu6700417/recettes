difficulte: moyen
ingredients:
  - { ingredient: farine, qte: 250, unite: g, groupe: "Pâte" }
  - { ingredient: beurre, qte: 125, unite: g, precision: froid, groupe: "Pâte" }
  - { ingredient: eau, qte: 50, unite: ml, precision: froide, groupe: "Pâte" }
  - { ingredient: sucre-en-poudre, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: "pincée", groupe: "Pâte" }
  - { ingredient: lait-entier, qte: 1, unite: l, groupe: "Appareil" }
  - { ingredient: oeuf, qte: 4, unite: "", groupe: "Appareil" }
  - { ingredient: sucre-en-poudre, qte: 150, unite: g, groupe: "Appareil" }
  - { ingredient: fecule-de-mais, qte: 80, unite: g, groupe: "Appareil" }
  - { ingredient: gousse-de-vanille, qte: 1, unite: "", groupe: "Appareil" }
etapes:
  - "Pâte : sabler la farine, le sel, le sucre et le beurre froid, ajouter l'eau et rassembler. Laisser reposer 1 heure au frais."
  - "Préchauffer le four à 180 °C. Abaisser la pâte à 3 mm, foncer un moule à tarte haut de 24 cm, piquer et cuire à blanc 15 minutes avec des poids."
  - "Porter à ébullition 75 cl de lait avec la vanille fendue et grattée."
  - "Fouetter les œufs avec le sucre et la fécule, délayer avec les 25 cl de lait froid restant. Verser le lait bouillant en filet en fouettant."
  - "Remettre sur le feu et cuire en fouettant jusqu'à l'ébullition, puis 1 minute de plus."
  - "Verser aussitôt la crème chaude dans le fond précuit et lisser."
  - "Cuire 40 minutes à 180 °C, jusqu'à ce que le dessus soit brun et le flan ferme au centre."
  - "Laisser refroidir complètement avant de démouler, au moins 4 heures."
