---
preparation: oeufs-benedicte
titre: Œufs Bénédicte classiques
reference: true
statut: relu-agent
portions: 2
temps: { preparation: 15, cuisson: 15 }
difficulte: moyen
ingredients:
  - { ingredient: oeuf, qte: 4, unite: "", precision: "très frais" }
  - { ingredient: vinaigre-blanc, qte: 1, unite: c. à soupe }
  - { ingredient: muffin-anglais, qte: 2, unite: "", precision: "coupés en deux" }
  - { ingredient: jambon-cuit, qte: 4, unite: tranche }
  - { ingredient: beurre, qte: 20, unite: g }
  - { preparation: hollandaise, qte: 150, unite: g }
  - { ingredient: ciboulette, qte: 1, unite: c. à soupe, precision: "ciselée" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Préparer la hollandaise et la garder tiède, à 50-55 °C, dans un bol sur de l'eau chaude hors du feu."
  - "Porter une grande casserole d'eau à frémissement, ajouter le vinaigre. Casser chaque œuf dans une tasse."
  - "Créer un léger tourbillon dans l'eau, y glisser un œuf et pocher 3 minutes. Égoutter à l'écumoire sur un torchon, recommencer pour les autres (par deux au plus à la fois)."
  - "Griller les moitiés de muffins et les beurrer ; poser dessus une tranche de jambon, éventuellement réchauffée à la poêle."
  - "Poser un œuf poché sur chaque moitié et napper de hollandaise. Poivrer, parsemer de ciboulette et servir aussitôt."
---

Si les œufs se déforment, les pocher dans une eau à 85-90 °C sans ébullition et utiliser des œufs
très frais. Ils peuvent être pochés à l'avance et réchauffés 30 secondes dans l'eau chaude.
