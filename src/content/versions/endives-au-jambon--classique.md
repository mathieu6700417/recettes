statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 55 }
difficulte: facile
ingredients:
  - { ingredient: endive, qte: 8, unite: "", precision: "moyennes et fermes" }
  - { ingredient: jambon-cuit, qte: 8, unite: tranche, precision: "fines" }
  - { preparation: bechamel, qte: 0.5, unite: l, precision: "fluide, relevée de muscade", groupe: "Sauce" }
  - { ingredient: gruyere, qte: 100, unite: g, precision: "râpé", groupe: "Sauce" }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée", groupe: "Sauce" }
  - { ingredient: beurre, qte: 40, unite: g, precision: "dont 15 g pour le plat" }
  - { ingredient: jus-de-citron, qte: 1, unite: c. à café }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Préchauffer le four à 200 °C. Retirer les feuilles abîmées des endives et couper la base du trognon sans les séparer ; ne pas les laisser tremper dans l'eau."
  - "Faire fondre 25 g de beurre dans une sauteuse, y ranger les endives, ajouter 10 cl d'eau, le jus de citron, une pincée de sel. Couvrir et braiser à feu doux 25 minutes, en les retournant à mi-cuisson."
  - "Les égoutter sur un linge et les presser doucement pour éliminer l'eau de cuisson."
  - "Préparer 0,5 l de béchamel fluide selon la recette de base, l'assaisonner de sel, de poivre et de muscade, et lui incorporer la moitié du gruyère."
  - "Enrouler chaque endive dans une tranche de jambon, les ranger côte à côte dans un plat beurré (15 g de beurre)."
  - "Napper de béchamel, parsemer du reste de gruyère."
  - "Enfourner 20 à 25 minutes, puis 5 minutes sous le gril, jusqu'à ce que la surface soit dorée et bouillonnante. Laisser reposer 5 minutes avant de servir."
---

Pour atténuer l'amertume, retirer le cône dur à la base de chaque endive avant le braisage.
