statut: relu-agent

difficulte: facile
ingredients:
  - { ingredient: moule, qte: 15, unite: "", precision: "restes de moules au curry, décortiquées, avec leur sauce" }
  - { ingredient: echalote, qte: 1, unite: "", precision: "ciselée" }
  - { ingredient: beurre, qte: 10, unite: g }
  - { ingredient: pomme-de-terre, qte: 1, unite: "", precision: "moyenne, en petits dés" }
  - { ingredient: eau, qte: 30, unite: cl }
  - { ingredient: lait-de-coco, qte: 20, unite: cl }
  - { ingredient: curry-en-poudre, qte: 0.5, unite: c. à café, precision: "si la sauce manque de goût" }
  - { ingredient: citron-vert, qte: 0.5, unite: "", precision: "le jus" }
  - { ingredient: coriandre-fraiche, qte: 2, unite: branche, precision: "ciselée" }
  - { ingredient: sel, qte: null, unite: "", precision: "seulement si nécessaire" }
etapes:
  - "Faire suer l'échalote dans le beurre 2 minutes dans une casserole, sans coloration."
  - "Ajouter la pomme de terre, la sauce des moules, l'eau et le curry si besoin. Laisser mijoter 15 minutes, jusqu'à ce que la pomme de terre s'écrase."
  - "Ajouter le lait de coco et 10 moules. Mixer finement."
  - "Remettre sur feu doux, ajouter les 5 moules restantes et réchauffer 2 minutes sans faire bouillir."
  - "Ajouter le jus de citron vert, goûter et saler si nécessaire. Servir parsemé de coriandre."
---

Sans lait de coco, la même quantité de crème liquide donne un velouté plus classique.
