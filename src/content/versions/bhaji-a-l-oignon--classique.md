ingredients:
  - { ingredient: oignon-jaune, qte: 3, unite: "", precision: "émincés finement", groupe: "Pâte" }
  - { ingredient: farine-de-pois-chiche, qte: 120, unite: g, groupe: "Pâte" }
  - { ingredient: graine-de-nigelle, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: cumin-en-graines, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: curcuma, qte: 0.5, unite: c. à café, groupe: "Pâte" }
  - { ingredient: piment-frais, qte: 1, unite: "", precision: "épépiné et haché", groupe: "Pâte" }
  - { ingredient: coriandre-fraiche, qte: 0.5, unite: botte, precision: "ciselée", groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: eau, qte: 8, unite: cl, precision: "environ", groupe: "Pâte" }
  - { ingredient: huile-neutre, qte: 75, unite: cl, precision: "pour la friture", groupe: "Friture" }
etapes:
  - "Mélanger les oignons émincés avec le sel et laisser dégorger 10 minutes."
  - "Ajouter la farine de pois chiche, la nigelle, le cumin, le curcuma, le piment et la coriandre. Mélanger avec les mains."
  - "Verser l'eau peu à peu en malaxant, jusqu'à obtenir une pâte épaisse qui enrobe les oignons sans couler."
  - "Chauffer l'huile à 170-180 °C dans une casserole haute ou une friteuse (un petit morceau de pâte doit remonter en grésillant)."
  - "Plonger des cuillerées de pâte, 4 ou 5 à la fois, et frire 4 à 5 minutes en les retournant, jusqu'à ce qu'ils soient dorés et croustillants."
  - "Égoutter sur du papier absorbant, saler légèrement et servir aussitôt, avec un chutney ou un yaourt à la menthe."
---

Environ 12 bhajis. L'huile de friture se filtre et se réutilise une fois. Sans garam masala ici : ni le profil ni le mélange ne conviennent à cette pâte, qui reste simple (curcuma, nigelle, cumin).
