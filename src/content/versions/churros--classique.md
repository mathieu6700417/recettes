---
preparation: churros
titre: "Version classique"
reference: true
statut: relu-agent
portions: 20
temps: { preparation: 20, cuisson: 20 }
difficulte: moyen
ingredients:
  - { ingredient: eau, qte: 250, unite: ml, groupe: "Pâte" }
  - { ingredient: huile-d-olive, qte: 2, unite: c. à soupe, precision: douce, groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: "pincée", groupe: "Pâte" }
  - { ingredient: farine, qte: 150, unite: g, groupe: "Pâte" }
  - { ingredient: huile-neutre, qte: 1, unite: l, precision: "de friture", groupe: "Friture" }
  - { ingredient: sucre-en-poudre, qte: 60, unite: g, groupe: "Finition" }
  - { ingredient: cannelle-en-poudre, qte: 1, unite: c. à café, groupe: "Finition" }
  - { ingredient: chocolat-noir, qte: 150, unite: g, groupe: "Chocolat chaud" }
  - { ingredient: lait-entier, qte: 30, unite: cl, groupe: "Chocolat chaud" }
  - { ingredient: fecule-de-mais, qte: 1, unite: c. à soupe, groupe: "Chocolat chaud" }
etapes:
  - "Porter à ébullition l'eau avec l'huile d'olive et le sel. Ajouter la farine d'un coup, mélanger vigoureusement jusqu'à former une boule lisse, sans dessécher longtemps."
  - "Laisser tiédir 5 minutes, puis lisser la pâte. Elle doit rester assez ferme pour sortir de la poche sans couler."
  - "Garnir une poche munie d'une grosse douille cannelée de 10 mm."
  - "Chauffer l'huile à 175 °C. Presser des bâtons de 12 cm, les couper aux ciseaux au ras de la douille et les plonger dans l'huile, 5 ou 6 à la fois."
  - "Frire 2 à 3 minutes en les retournant, jusqu'à ce qu'ils soient dorés. Égoutter sur papier absorbant."
  - "Rouler les churros dans le sucre mélangé à la cannelle."
  - "Chocolat chaud : délayer la fécule dans un peu de lait froid. Chauffer le reste du lait, ajouter le chocolat haché et la fécule, puis cuire en fouettant 1 minute jusqu'à épaississement. Servir pour tremper."
---

Les 20 portions sont des bâtons de 12 cm.
