---
preparation: crumble-aux-pommes
titre: "Version classique"
reference: true
statut: relu-agent
portions: 6
temps: { preparation: 20, cuisson: 40 }
difficulte: facile
ingredients:
  - { ingredient: pomme, qte: 1, unite: kg, precision: "pelées, en cubes", groupe: "Pommes" }
  - { ingredient: cassonade, qte: 30, unite: g, groupe: "Pommes" }
  - { ingredient: beurre, qte: 20, unite: g, groupe: "Pommes" }
  - { ingredient: farine, qte: 150, unite: g, groupe: "Crumble" }
  - { ingredient: beurre, qte: 100, unite: g, precision: "froid, en dés", groupe: "Crumble" }
  - { ingredient: cassonade, qte: 100, unite: g, groupe: "Crumble" }
  - { ingredient: poudre-d-amande, qte: 50, unite: g, groupe: "Crumble" }
  - { ingredient: sel, qte: 1, unite: pincée, groupe: "Crumble" }
etapes:
  - "Préchauffer le four à 180 °C. Beurrer un plat."
  - "Faire revenir les pommes 5 minutes à la poêle avec 20 g de beurre et 30 g de cassonade, puis les verser dans le plat."
  - "Mélanger farine, 100 g de cassonade, poudre d'amande et sel. Ajouter le beurre froid en dés."
  - "Sabler du bout des doigts jusqu'à obtenir des miettes irrégulières, sans former de boule."
  - "Répartir le crumble en vrac sur les pommes, sans tasser."
  - "Cuire 35 à 40 minutes à 180 °C, jusqu'à ce que le dessus soit doré et que le jus bouillonne. Servir tiède."
---

Se mange avec de la crème fraîche, de la glace à la vanille ou de la crème anglaise.
