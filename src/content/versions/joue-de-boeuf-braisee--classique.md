  - { ingredient: carotte, qte: 2, unite: "" }

  - { ingredient: concentre-de-tomate, qte: 1, unite: c. à soupe }
  - { ingredient: vin-rouge, qte: 50, unite: cl }
  - { preparation: fond-brun, qte: 30, unite: cl }
  - { ingredient: thym, qte: 1, unite: branche, precision: "bouquet garni" }
  - { ingredient: laurier, qte: 1, unite: "", precision: "bouquet garni" }

etapes:
  - "Chauffer le four à 150 °C. Saler et poivrer les joues, bien les sécher."
  - "Dans une cocotte, saisir les joues dans l'huile très chaude, 4 minutes par face. Réserver."
  - "Faire revenir oignon et carottes en dés 5 minutes, ajouter l'ail et le concentré de tomate, cuire 2 minutes."
  - "Déglacer au vin rouge, réduire de moitié, verser le fond brun, remettre les joues : le liquide doit atteindre à peine mi-hauteur. Ajouter le bouquet garni."
  - "Couvrir et cuire au four 3 h à 3 h 15, en retournant les joues à mi-cuisson. Elles doivent se couper à la cuillère."
  - "Réserver la viande au chaud, passer et réduire la sauce de moitié, hors du feu monter au beurre froid. Napper et servir avec une purée."
