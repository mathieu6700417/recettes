---
preparation: bortsch
titre: Version classique
reference: true
statut: relu-agent
portions: 6
temps: { preparation: 30, cuisson: 120 }
difficulte: moyen
ingredients:
  - { ingredient: boeuf-a-braiser, qte: 500, unite: g, precision: "jarret ou plat de côtes, en un morceau", groupe: "Bouillon" }
  - { ingredient: eau, qte: 2, unite: l, groupe: "Bouillon" }
  - { ingredient: laurier, qte: 2, unite: feuille, groupe: "Bouillon" }
  - { ingredient: pomme-de-terre, qte: 300, unite: g, precision: "en cubes de 2 cm", groupe: "Légumes" }
  - { ingredient: chou-blanc, qte: 300, unite: g, precision: "émincé finement", groupe: "Légumes" }
  - { ingredient: betterave, qte: 400, unite: g, precision: "crue, épluchée et râpée", groupe: "Sauteuse" }
  - { ingredient: carotte, qte: 2, unite: "", precision: "râpées", groupe: "Sauteuse" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "haché", groupe: "Sauteuse" }
  - { ingredient: huile-neutre, qte: 3, unite: c. à soupe, groupe: "Sauteuse" }
  - { ingredient: concentre-de-tomate, qte: 2, unite: c. à soupe, groupe: "Sauteuse" }
  - { ingredient: vinaigre-de-vin, qte: 2, unite: c. à soupe, groupe: "Sauteuse" }
  - { ingredient: ail, qte: 2, unite: gousse, precision: "écrasées", groupe: "Finition" }
  - { ingredient: persil, qte: 1, unite: botte, precision: "ciselé", groupe: "Finition" }
  - { ingredient: creme-aigre, qte: 150, unite: g, groupe: "Finition" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Mettre le bœuf dans une grande marmite avec l'eau froide et le laurier. Porter à frémissement, écumer soigneusement, puis laisser mijoter à feu très doux, à moitié couvert, 1 h 15."
  - "Pendant ce temps, faire chauffer l'huile dans une sauteuse. Y faire suer l'oignon 3 minutes, ajouter la carotte et la betterave râpées, puis le concentré de tomate et le vinaigre. Mouiller d'une louche de bouillon et cuire 15 minutes à couvert."
  - "Retirer le bœuf du bouillon et le couper en morceaux. Ajouter les pommes de terre dans le bouillon et cuire 10 minutes."
  - "Ajouter le chou et cuire encore 10 minutes."
  - "Verser le contenu de la sauteuse dans la marmite avec la viande. Laisser frémir 10 minutes de plus. Saler et poivrer."
  - "Hors du feu, ajouter l'ail et la moitié du persil, couvrir et laisser reposer 30 minutes."
  - "Servir très chaud, avec une cuillerée de crème aigre et le reste du persil. Le pain de seigle accompagne bien."
---

Le bortsch se conserve 3 jours au réfrigérateur et se réchauffe sans bouillir. L'aneth, traditionnel au service, est omis ici : hors saison en novembre, le persil le remplace.
