---
preparation: risotto-aux-champignons
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 30 }
difficulte: moyen
ingredients:
  - { ingredient: riz-carnaroli, qte: 320, unite: g }
  - { preparation: fond-de-legumes, qte: 1.2, unite: l, precision: "maintenu frémissant" }
  - { ingredient: cepe, qte: 300, unite: g, precision: "nettoyés, en lamelles" }
  - { ingredient: champignon-de-paris, qte: 200, unite: g, precision: "nettoyés, en lamelles" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "petit, finement haché" }
  - { ingredient: beurre, qte: 80, unite: g, precision: "dont 40 g froid, en dés, pour la mantecatura" }
  - { ingredient: huile-d-olive, qte: 2, unite: c. à soupe }
  - { ingredient: vin-blanc, qte: 100, unite: ml, precision: "sec" }
  - { ingredient: parmesan, qte: 60, unite: g, precision: "fraîchement râpé" }
  - { ingredient: persil, qte: 3, unite: branche, precision: "ciselé" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Garder le fond de légumes à frémissement dans une casserole à côté."
  - "Chauffer l'huile dans une grande poêle à feu vif. Y saisir les champignons en deux fois, 4 à 5 minutes, jusqu'à belle coloration. Saler, poivrer et réserver."
  - "Faire fondre 40 g de beurre à feu moyen dans une large casserole à fond épais. Y faire fondre l'oignon 5 minutes, sans coloration."
  - "Ajouter le riz et le nacrer 2 minutes en remuant, jusqu'à ce que les grains soient chauds et translucides sur les bords."
  - "Verser le vin blanc et laisser évaporer complètement en remuant, environ 1 minute."
  - "Mouiller d'une louche de fond chaud. Remuer jusqu'à absorption presque totale, puis ajouter la louche suivante. Poursuivre ainsi 16 à 18 minutes à feu moyen."
  - "Ajouter les champignons 3 minutes avant la fin de cuisson. Saler légèrement."
  - "Quand le riz est tendre à cœur mais encore ferme, et le risotto fluide, retirer du feu."
  - "Mantecatura : ajouter hors du feu les 40 g de beurre froid en dés et le parmesan. Remuer vigoureusement, couvrir et laisser reposer 2 minutes. Parsemer de persil et servir aussitôt dans des assiettes creuses."
---

Faute de cèpes frais, utiliser des champignons de Paris seuls, avec une cuillerée de cèpes secs réhydratés dont on ajoute l'eau filtrée au fond.
