---
preparation: chowder-aux-moules
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 30, cuisson: 35 }
difficulte: facile
ingredients:
  - { ingredient: moule, qte: 1.5, unite: kg, precision: "grattées et rincées" }
  - { ingredient: vin-blanc, qte: 10, unite: cl, precision: "sec" }
  - { ingredient: bacon, qte: 150, unite: g, precision: "en lardons" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "en petits dés" }
  - { ingredient: celeri-branche, qte: 2, unite: branche, precision: "en petits dés" }
  - { ingredient: beurre, qte: 20, unite: g }
  - { ingredient: farine, qte: 1, unite: c. à soupe }
  - { ingredient: pomme-de-terre-a-chair-ferme, qte: 500, unite: g, precision: "en dés de 1,5 cm" }
  - { ingredient: lait-entier, qte: 50, unite: cl }
  - { ingredient: thym, qte: 2, unite: branche }
  - { ingredient: laurier, qte: 1, unite: "" }
  - { ingredient: creme-liquide, qte: 15, unite: cl }
  - { ingredient: persil-plat, qte: 2, unite: branche, precision: "haché" }
  - { ingredient: poivre, qte: null, unite: "" }
  - { ingredient: sel, qte: null, unite: "", precision: "seulement si nécessaire" }
etapes:
  - "Gratter les moules, retirer les byssus et les rincer. Jeter celles qui sont cassées ou qui restent ouvertes quand on les tapote."
  - "Dans une grande cocotte, porter le vin blanc à ébullition, ajouter les moules, couvrir et cuire à feu vif 5 minutes en secouant, jusqu'à ce qu'elles soient ouvertes."
  - "Égoutter les moules au-dessus d'un saladier, les décortiquer et les réserver. Filtrer le jus à travers un linge fin ou un filtre à café ; on doit en obtenir environ 30 cl, compléter d'eau si besoin."
  - "Dans la cocotte rincée, faire dorer le lard à feu moyen 5 minutes. Ajouter le beurre, l'oignon et le céleri, et les faire suer 5 minutes sans coloration."
  - "Saupoudrer de farine et remuer 1 minute. Verser peu à peu le jus des moules en remuant, puis le lait. Ajouter les pommes de terre, le thym et le laurier."
  - "Laisser mijoter à feu doux 15 à 20 minutes, sans bouillir, jusqu'à ce que les pommes de terre soient tendres. Écraser quelques dés contre la paroi pour épaissir la soupe."
  - "Retirer le thym et le laurier, ajouter la crème et les moules décortiquées, réchauffer 2 minutes sans bouillir. Poivrer, goûter et saler si nécessaire."
  - "Servir parsemé de persil, avec des crackers ou du pain grillé."
---

Avec des palourdes à la place des moules, on obtient le clam chowder classique de Nouvelle-Angleterre.
