---
preparation: flamiche-aux-poireaux
titre: Version classique
reference: true
statut: relu-agent
portions: 6
temps: { preparation: 35, cuisson: 60, repos: 60 }
difficulte: facile
ingredients:
  - { ingredient: farine, qte: 250, unite: g, groupe: "Pâte" }
  - { ingredient: beurre, qte: 125, unite: g, precision: froid, groupe: "Pâte" }
  - { ingredient: eau, qte: 50, unite: ml, precision: froide, groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: poireau, qte: 800, unite: g, precision: "blancs et vert tendre, lavés et émincés", groupe: "Garniture" }
  - { ingredient: beurre, qte: 40, unite: g, groupe: "Garniture" }
  - { ingredient: oeuf, qte: 3, unite: "", groupe: "Appareil" }
  - { ingredient: creme-liquide, qte: 25, unite: cl, groupe: "Appareil" }
  - { ingredient: lait-entier, qte: 10, unite: cl, groupe: "Appareil" }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée", groupe: "Appareil" }
  - { ingredient: sel, qte: null, unite: "", groupe: "Appareil" }
  - { ingredient: poivre, qte: null, unite: "", groupe: "Appareil" }
etapes:
  - "Pâte : sabler la farine, le sel et le beurre froid en dés du bout des doigts, ajouter l'eau, rassembler sans pétrir. Former une boule, filmer et laisser reposer 1 heure au frais."
  - "Faire fondre le beurre de la garniture dans une sauteuse. Y ajouter les poireaux, saler légèrement, couvrir et cuire à feu doux 20 minutes en remuant, jusqu'à ce qu'ils soient fondants. Découvrir en fin de cuisson pour évaporer l'eau, puis laisser tiédir."
  - "Préchauffer le four à 180 °C. Abaisser la pâte à 3 mm, foncer un moule de 28 cm et piquer le fond à la fourchette."
  - "Cuire à blanc 15 minutes, garni de papier sulfurisé et de poids."
  - "Fouetter les œufs avec la crème, le lait, la muscade et le poivre. Saler peu."
  - "Étaler les poireaux sur le fond précuit, verser l'appareil par-dessus."
  - "Cuire 30 à 35 minutes à 180 °C, jusqu'à ce que l'appareil soit pris et doré, mais encore légèrement tremblant au centre."
  - "Laisser tiédir 10 minutes avant de servir, avec une salade verte."
---

La flamiche se réchauffe très bien 10 minutes au four le lendemain.
