titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 75 }
difficulte: facile
ingredients:
  - { ingredient: cuisse-de-poulet, qte: 8, unite: "", precision: "pilons et hauts de cuisse" }
  - { ingredient: oignon, qte: 3, unite: "", precision: "émincés" }
  - { ingredient: ail, qte: 3, unite: gousse, precision: "hachées" }
  - { ingredient: ras-el-hanout-en-poudre, qte: 2, unite: "c. à café" }
  - { ingredient: gingembre-moulu, qte: 1, unite: "c. à café" }
  - { ingredient: safran, qte: 1, unite: pincée }
  - { ingredient: citron-confit, qte: 2, unite: "", precision: "rincés, écorce en lanières" }
  - { ingredient: olive-verte, qte: 150, unite: g, precision: "dénoyautées" }
  - { ingredient: coriandre-fraiche, qte: 0.5, unite: botte, precision: "ciselée" }
  - { ingredient: persil-plat, qte: 0.5, unite: botte, precision: "ciselé" }
  - { ingredient: huile-d-olive, qte: 3, unite: "c. à soupe" }
  - { ingredient: eau, qte: 25, unite: cl }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Mélanger le ras-el-hanout, le gingembre, le safran, du sel et du poivre avec 1 c. à soupe d'huile. Frotter les morceaux de poulet et laisser reposer 30 minutes."
  - "Chauffer le reste de l'huile dans un tajine ou une cocotte, dorer le poulet 3 à 4 minutes par face. Réserver."
  - "Faire fondre les oignons et l'ail 10 minutes à feu moyen sans coloration."
  - "Remettre le poulet, verser l'eau, couvrir et cuire 45 minutes à feu très doux, à frémissement."
  - "Ajouter les olives et les lanières de citron confit. Poursuivre 15 minutes à couvert : le poulet doit être tendre, la sauce courte (cuisson à cœur au minimum 75 °C)."
  - "Parsemer de coriandre et de persil. Servir avec de la semoule ou du pain."
---

Variante rapide : à défaut de tajine, utiliser une cocotte en fonte à couvercle serré, four à 170 °C.
