ingredients:
  - { ingredient: poire, qte: 6, unite: "", precision: "fermes", groupe: "Poires" }
  - { ingredient: eau, qte: 1, unite: l, groupe: "Poires" }
  - { ingredient: sucre-en-poudre, qte: 200, unite: g, groupe: "Poires" }
  - { ingredient: gousse-de-vanille, qte: 1, unite: "", groupe: "Poires" }
  - { ingredient: jus-de-citron, qte: 2, unite: c. à soupe, groupe: "Poires" }
  - { ingredient: chocolat-noir, qte: 200, unite: g, groupe: "Sauce" }
  - { ingredient: creme-liquide, qte: 15, unite: cl, groupe: "Sauce" }
  - { ingredient: lait-entier, qte: 10, unite: cl, groupe: "Sauce" }
  - { ingredient: glace-a-la-vanille, qte: 500, unite: ml, groupe: "Service" }
etapes:
  - "Porter à frémissement l'eau, le sucre et la gousse de vanille fendue, avec le jus de citron."
  - "Peler les poires en gardant la queue, les citronner au fur et à mesure, les plonger dans le sirop."
  - "Pocher à frémissement 20 à 25 minutes, jusqu'à ce que la pointe d'un couteau entre sans résistance. Laisser refroidir dans le sirop."
  - "Chauffer le lait et la crème, verser sur le chocolat haché, lisser à la spatule."
  - "Égoutter les poires. Dresser dans des coupes avec une boule de glace, napper de sauce chocolat chaude."
---

Les poires peuvent se pocher la veille ; le sirop se garde et sert à nouveau.
