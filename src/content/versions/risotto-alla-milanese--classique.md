---
preparation: risotto-alla-milanese
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 10, cuisson: 25 }
difficulte: moyen
ingredients:
  - { ingredient: riz-carnaroli, qte: 320, unite: g }
  - { preparation: fond-blanc, qte: 1.2, unite: l, precision: "bouillon de volaille, maintenu frémissant" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "petit, finement haché" }
  - { ingredient: beurre, qte: 80, unite: g, precision: "dont 40 g froid, en dés, pour la mantecatura" }
  - { ingredient: vin-blanc, qte: 100, unite: ml, precision: "sec" }
  - { ingredient: safran, qte: 2, unite: pincée, precision: "en pistils" }
  - { ingredient: parmesan, qte: 60, unite: g, precision: "fraîchement râpé" }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Faire infuser le safran dans 100 ml de bouillon chaud. Garder le reste du bouillon à frémissement dans une casserole à côté."
  - "Faire fondre 40 g de beurre à feu moyen dans une large casserole à fond épais. Y faire fondre l'oignon 5 minutes, sans coloration."
  - "Ajouter le riz et le nacrer 2 minutes en remuant, jusqu'à ce que les grains soient chauds et translucides sur les bords."
  - "Verser le vin blanc et laisser évaporer complètement en remuant, environ 1 minute."
  - "Mouiller d'une louche de bouillon chaud. Remuer jusqu'à absorption presque totale, puis ajouter la louche suivante. Poursuivre ainsi 16 à 18 minutes, à feu moyen."
  - "Aux deux tiers de la cuisson (environ 12 minutes), verser le bouillon au safran. Saler légèrement en fin de cuisson."
  - "Quand le riz est tendre à cœur mais encore ferme, et le risotto fluide, retirer du feu."
  - "Mantecatura : ajouter hors du feu les 40 g de beurre froid en dés et le parmesan. Remuer vigoureusement, couvrir et laisser reposer 2 minutes. Servir aussitôt, dans des assiettes creuses."
---

Le risotto doit napper et s'étaler en vague dans l'assiette. Si besoin, ajouter une dernière louche de bouillon avant la mantecatura.
