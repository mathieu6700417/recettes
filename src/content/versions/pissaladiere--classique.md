---
preparation: pissaladiere
titre: "Version classique"
reference: true
statut: relu-agent
portions: 6
temps: { preparation: 30, cuisson: 25, repos: 135 }
difficulte: moyen
ingredients:
  - { preparation: pate-a-pain, qte: 500, unite: g, groupe: "Pâte" }
  - { preparation: compotee-d-oignons, qte: 500, unite: g, groupe: "Garniture" }
  - { ingredient: anchois, qte: 12, unite: "", precision: "filets à l'huile", groupe: "Garniture" }
  - { ingredient: olive-noire, qte: 100, unite: g, precision: "de Nice, si possible", groupe: "Garniture" }
  - { ingredient: herbes-de-provence, qte: 1, unite: c. à café, groupe: "Garniture" }
  - { ingredient: huile-d-olive, qte: 2, unite: c. à soupe, groupe: "Garniture" }
  - { ingredient: poivre, qte: null, unite: "", groupe: "Garniture" }
etapes:
  - "Préparer la pâte à pain (avec les 2 c. à soupe d'huile d'olive facultatives de sa recette) et la compotée d'oignons (environ 1,5 kg d'oignons pour 500 g de compotée). Laisser la compotée refroidir."
  - "Préchauffer le four à 220 °C avec une plaque dedans."
  - "Étaler la pâte levée en rectangle d'environ 30 × 40 cm sur du papier sulfurisé. Laisser reposer 15 minutes."
  - "Étaler la compotée sur toute la surface en laissant 1 cm de bord. Poivrer et parsemer d'herbes de Provence."
  - "Disposer les filets d'anchois en croisillons et poser une olive noire dans chaque losange."
  - "Arroser d'un filet d'huile d'olive. Glisser la pissaladière avec son papier sur la plaque chaude."
  - "Cuire 20 à 25 minutes, jusqu'à ce que les bords soient dorés. Servir tiède ou à température ambiante."
---

La pâte et la compotée se préparent à part (les temps indiqués ne comptent que l'assemblage et la cuisson, hors la pousse de la pâte, comptée en repos). La compotée est déjà salée : ne pas resaler. Les olives gardent leur noyau dans la version niçoise ; prévenir les convives.
