temps: { preparation: 40, cuisson: 120, repos: 60 }
difficulte: moyen
ingredients:
  - { preparation: meringue, qte: 1, unite: "", groupe: "Meringue" }
  - { ingredient: creme-liquide, qte: 40, unite: cl, precision: "très froide", groupe: "Chantilly" }
  - { ingredient: sucre-glace, qte: 30, unite: g, groupe: "Chantilly" }
  - { ingredient: gousse-de-vanille, qte: 1, unite: "", groupe: "Chantilly" }
  - { ingredient: creme-de-marrons, qte: 500, unite: g, groupe: "Marrons" }
  - { ingredient: chataigne, qte: 100, unite: g, precision: "cuites, émiettées", groupe: "Marrons" }
etapes:
  - "Préparer la meringue (voir la base) en 8 nids de 8 cm de large, creusés au centre, et la sécher au four à 100 °C. Laisser refroidir dans le four éteint."
  - "Fendre et gratter la vanille dans la crème liquide très froide, fouetter avec le sucre glace en chantilly souple."
  - "Mélanger la crème de marrons avec les châtaignes émiettées, puis la passer à travers une grille ou un presse-purée pour obtenir des vermicelles."
  - "Au moment de servir, garnir chaque nid d'une cuillerée de chantilly."
  - "Coiffer de vermicelles de marrons en formant un dôme. Servir aussitôt."
---

Les nids se préparent plusieurs jours à l'avance, à garder dans une boîte hermétique.
