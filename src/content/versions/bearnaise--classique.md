ingredients:
  - { ingredient: echalote, qte: 2, unite: "", precision: "ciselées" }
  - { ingredient: vinaigre-de-vin, qte: 10, unite: cl, groupe: "Réduction" }
  - { ingredient: vin-blanc, qte: 5, unite: cl, groupe: "Réduction" }
  - { ingredient: estragon, qte: 2, unite: branche, groupe: "Réduction", precision: "hachées, un peu mises de côté pour la finition" }
  - { ingredient: poivre, qte: null, unite: "", groupe: "Réduction", precision: "concassé" }
  - { ingredient: jaune-d-oeuf, qte: 3, unite: "", groupe: "Sauce" }
  - { ingredient: beurre-clarifie, qte: 200, unite: g, groupe: "Sauce", precision: "tiède" }
  - { ingredient: cerfeuil, qte: 1, unite: c. à soupe, groupe: "Sauce", precision: "haché" }
  - { ingredient: sel, qte: 1, unite: pincée, groupe: "Sauce" }
  - { ingredient: piment-de-cayenne, qte: 1, unite: pincée, groupe: "Sauce" }
etapes:
  - "Dans une petite casserole, réunir échalotes, vinaigre, vin blanc, la moitié de l'estragon et le poivre. Réduire à feu moyen jusqu'à ne plus avoir que 3 c. à soupe de liquide."
  - "Filtrer la réduction en pressant bien et la laisser tiédir."
  - "Clarifier le beurre et le garder tiède, vers 50 °C."
  - "Dans un bol sur bain-marie frémissant, fouetter les jaunes avec la réduction jusqu'à obtenir un sabayon épais et mousseux qui nappe le fouet (60 à 65 °C)."
  - "Retirer du feu, verser le beurre clarifié en filet en fouettant, goutte à goutte au début."
  - "Ajouter le reste d'estragon et le cerfeuil hachés, saler, relever d'une pointe de cayenne. Servir aussitôt, tiède."
---

Même rattrapage que la hollandaise : reprendre la sauce tranchée en filet dans 1 c. à soupe d'eau tiède
fouettée. Une réduction trop poussée rend la sauce trop acide ; ajuster avec un peu d'eau tiède.
