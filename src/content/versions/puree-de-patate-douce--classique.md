---
preparation: puree-de-patate-douce
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 15, cuisson: 20 }
difficulte: facile
ingredients:
  - { ingredient: patate-douce, qte: 900, unite: g, precision: "pelées, en morceaux de 3 cm" }
  - { ingredient: beurre, qte: 40, unite: g }
  - { ingredient: lait, qte: 10, unite: cl, precision: "tiède" }
  - { ingredient: creme-liquide, qte: 10, unite: cl, precision: "tiède" }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée" }
  - { ingredient: eau, qte: 1, unite: l, precision: "pour la cuisson" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Placer les morceaux de patate douce dans une casserole, couvrir d'eau froide salée et porter à frémissement."
  - "Mijoter 15 à 20 minutes, jusqu'à ce qu'un couteau s'enfonce sans résistance."
  - "Égoutter très soigneusement, puis remettre les morceaux dans la casserole sur feu doux 1 minute pour évaporer l'eau restante."
  - "Écraser au presse-purée (ou mixer brièvement) avec le beurre."
  - "Incorporer le lait et la crème tièdes en fouettant, jusqu'à la consistance voulue."
  - "Assaisonner de sel, de poivre et de muscade. Servir aussitôt."
---

À la vapeur, compter 20 à 25 minutes : la purée est plus ferme et demande souvent un peu moins de lait.
