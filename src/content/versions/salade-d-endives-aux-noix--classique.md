ingredients:
  - { ingredient: endive, qte: 4, unite: "", precision: "émincées en tronçons" }
  - { ingredient: pomme, qte: 1, unite: "", precision: "ferme, en dés" }
  - { ingredient: noix, qte: 60, unite: g, precision: "cerneaux, grossièrement concassés" }
  - { ingredient: roquefort, qte: 80, unite: g, precision: "émietté" }
  - { ingredient: roquette, qte: 40, unite: g, precision: "facultatif" }
  - { preparation: vinaigrette, qte: 10, unite: cl, groupe: "Assaisonnement" }
  - { ingredient: huile-de-noix, qte: 1, unite: c. à soupe, groupe: "Assaisonnement" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Préparer la vinaigrette : dissoudre une pincée de sel dans 2 c. à soupe de vinaigre de vin, ajouter 1 c. à café de moutarde, fouetter en incorporant 6 c. à soupe d'huile en filet, puis 1 c. à soupe d'huile de noix."
  - "Essuyer les endives, retirer la base du trognon et les émincer en tronçons de 2 cm."
  - "Couper la pomme en dés et la mélanger aussitôt avec un peu de vinaigrette."
  - "Réunir dans un saladier les endives, la roquette, la pomme et les noix."
  - "Assaisonner avec le reste de vinaigrette, ajouter le roquefort émietté et poivrer. Servir aussitôt."
---

Torréfier les noix 5 minutes à sec dans une poêle leur donne plus de parfum.
