ingredients:
  - { ingredient: epaule-d-agneau, qte: 800, unite: g, precision: "en cubes de 4 cm" }
  - { ingredient: yaourt, qte: 150, unite: g, precision: "nature" }
  - { ingredient: oignon, qte: 3, unite: "", precision: "émincés" }
  - { ingredient: ail, qte: 4, unite: gousse, precision: "hachées" }
  - { ingredient: gingembre-frais, qte: 30, unite: g, precision: "râpé" }
  - { ingredient: tomate-pelee, qte: 400, unite: g }
  - { ingredient: cumin-moulu, qte: 2, unite: "c. à café" }
  - { ingredient: coriandre-graine, qte: 2, unite: "c. à café", precision: "moulue" }
  - { ingredient: curcuma, qte: 1, unite: "c. à café" }
  - { ingredient: piment-de-cayenne, qte: 0.5, unite: "c. à café", precision: "à ajuster" }
  - { ingredient: garam-masala-en-poudre, qte: 2, unite: "c. à café" }
  - { ingredient: ghee, qte: 3, unite: "c. à soupe", precision: "ou huile neutre" }
  - { ingredient: coriandre-fraiche, qte: 0.5, unite: botte, precision: "ciselée" }
  - { ingredient: eau, qte: 30, unite: cl }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Mélanger l'agneau avec le yaourt, la moitié du gingembre, le curcuma et du sel. Laisser mariner 1 heure au frais."
  - "Dans une cocotte, chauffer le ghee et dorer les oignons 15 minutes à feu moyen, jusqu'à belle coloration brune."
  - "Ajouter l'ail et le reste du gingembre 1 minute, puis le cumin, la coriandre et le cayenne 1 minute en remuant."
  - "Ajouter l'agneau avec sa marinade et saisir 5 minutes en remuant."
  - "Ajouter les tomates écrasées et l'eau, saler. Porter à frémissement, couvrir et cuire 1 h 15 à feu doux, jusqu'à ce que la viande soit tendre."
  - "Hors du feu, ajouter le garam masala, laisser reposer 5 minutes, parsemer de coriandre fraîche. Servir avec du riz basmati."
