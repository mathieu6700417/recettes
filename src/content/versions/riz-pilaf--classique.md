---
preparation: riz-pilaf
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 10, cuisson: 25 }
difficulte: facile
ingredients:
  - { ingredient: riz-long, qte: 300, unite: g, precision: "environ 350 ml en volume" }
  - { preparation: fond-blanc, qte: 525, unite: ml, precision: "bouillon de volaille bouillant" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "petit, haché fin" }
  - { ingredient: beurre, qte: 40, unite: g, precision: "dont 10 g pour la finition" }
  - { ingredient: thym, qte: 1, unite: branche }
  - { ingredient: laurier, qte: 1, unite: "" }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Préchauffer le four à 180 °C. Porter le bouillon à ébullition."
  - "Dans une cocotte allant au four, faire fondre 30 g de beurre à feu moyen. Y faire suer l'oignon 3 minutes, sans coloration."
  - "Ajouter le riz non lavé et le nacrer 2 minutes en remuant, jusqu'à ce que les grains soient translucides."
  - "Verser le bouillon bouillant d'un coup (525 ml, soit 1,5 volume), ajouter le thym, le laurier et du sel. Porter à frémissement."
  - "Couvrir hermétiquement (papier sulfurisé sous le couvercle si besoin) et enfourner 18 minutes, sans ouvrir."
  - "Sortir du four et laisser reposer couvert 5 minutes. Retirer le thym et le laurier, ajouter le reste du beurre et égrener à la fourchette."
---

Le riz long non lavé garde son amidon de surface, qui est précisément ce que le nacrage fixe pour des grains détachés.
