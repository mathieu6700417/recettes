---
preparation: bechamel
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps:
  preparation: 5
  cuisson: 15
difficulte: facile
ingredients:
  - { ingredient: beurre, qte: 50, unite: g }
  - { ingredient: farine, qte: 50, unite: g }
  - { ingredient: lait, qte: 1, unite: l }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre-blanc, qte: null, unite: "" }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée }
etapes:
  - Faire fondre le beurre à feu moyen dans une casserole à fond épais.
  - Ajouter la farine d'un coup et cuire 2 minutes en remuant, sans laisser colorer.
  - Verser le lait petit à petit en fouettant, pour éviter les grumeaux.
  - Porter à ébullition en remuant, puis cuire 10 minutes à feu doux en grattant le fond.
  - Assaisonner de sel, de poivre blanc et d'une pincée de muscade. Filmer au contact si la sauce n'est pas utilisée tout de suite.
---

Rendement : environ 1 l de sauce mi-épaisse. Pour un gratin, compter 25 à 30 cl de béchamel pour 800 g de légumes.
