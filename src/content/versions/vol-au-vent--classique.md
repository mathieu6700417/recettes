ingredients:
  - { preparation: pate-feuilletee, qte: 500, unite: g, groupe: "Croûtes" }
  - { ingredient: jaune-d-oeuf, qte: 1, unite: "", groupe: "Croûtes", precision: "battu avec un peu d'eau, pour dorer" }
  - { ingredient: ris-de-veau, qte: 300, unite: g, groupe: "Garniture", precision: "dégorgé" }
  - { ingredient: blanc-de-poulet, qte: 200, unite: g, groupe: "Garniture" }
  - { ingredient: champignon-de-paris, qte: 200, unite: g, groupe: "Garniture", precision: "émincés" }
  - { ingredient: quenelle, qte: 8, unite: "", groupe: "Garniture", precision: "petites" }
  - { ingredient: beurre, qte: 30, unite: g, groupe: "Garniture" }
  - { ingredient: jus-de-citron, qte: 1, unite: c. à soupe, groupe: "Garniture" }
  - { preparation: veloute, qte: 500, unite: ml, groupe: "Sauce suprême", precision: "velouté de volaille" }
  - { ingredient: creme-liquide, qte: 10, unite: cl, groupe: "Sauce suprême" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre-blanc, qte: null, unite: "" }
etapes:
  - "Croûtes : préchauffer le four à 220 °C. Abaisser la pâte feuilletée à 5 mm d'épaisseur. Découper 8 disques de 12 cm de diamètre et évider 4 d'entre eux à l'emporte-pièce de 8 cm pour former des couronnes (garder les centres). Souder une couronne sur chacun des 4 disques entiers avec un peu d'eau."
  - "Dorer le dessus au jaune d'œuf sans en faire couler sur les côtés, rayer légèrement, et réserver 30 minutes au frais."
  - "Enfourner à 220 °C pendant 10 minutes, baisser à 180 °C et poursuivre 20 minutes, jusqu'à ce que les croûtes soient hautes et dorées (les centres sont cuits en 15 minutes). Cuire les centres évidés à côté, pour servir de couvercles ; vider l'intérieur mou des croûtes."
  - "Pocher le ris de veau 10 minutes dans de l'eau frémissante salée et citronnée, le refroidir, le dénerver et le couper en morceaux."
  - "Pocher le blanc de poulet 12 minutes dans l'eau frémissante, puis le couper en dés. Pocher les quenelles 10 minutes dans l'eau frémissante salée."
  - "Faire sauter les champignons dans le beurre avec le jus de citron, 5 minutes à feu vif, puis ajouter le ris de veau et le poulet."
  - "Sauce suprême : chauffer le velouté, lier avec la crème et laisser réduire 5 minutes à feu doux. Assaisonner de sel et de poivre blanc."
  - "Mêler la garniture et les quenelles à la sauce, chauffer 3 minutes. Réchauffer les croûtes 5 minutes à 160 °C, garnir généreusement et coiffer du couvercle. Servir aussitôt."
---
