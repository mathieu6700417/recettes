---
preparation: steak-au-poivre
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 10, cuisson: 18 }
difficulte: facile
ingredients:
  - { ingredient: faux-filet, qte: 4, unite: "", precision: "de 180 g, 2,5 cm d'épaisseur, sortis du froid 30 minutes avant" }
  - { ingredient: poivre, qte: 2, unite: c. à soupe, precision: "concassé grossièrement" }
  - { ingredient: beurre, qte: 30, unite: g }
  - { ingredient: huile-neutre, qte: 1, unite: c. à soupe }
  - { ingredient: echalote, qte: 1, unite: "", precision: "ciselée" }
  - { ingredient: cognac, qte: 6, unite: cl }
  - { ingredient: creme-liquide, qte: 20, unite: cl }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Étaler le poivre concassé sur une assiette et presser chaque face des steaks dedans, pour former une croûte."
  - "Chauffer l'huile et la moitié du beurre dans une grande poêle à feu vif. Saisir les steaks 3 minutes sur chaque face pour une cuisson saignante (4 minutes pour à point)."
  - "Saler les steaks, les retirer de la poêle et les tenir au chaud sous une feuille d'aluminium."
  - "Baisser à feu moyen, ajouter le reste du beurre et faire suer l'échalote 1 minute."
  - "Hors du feu, verser le cognac. Remettre sur le feu et flamber, en grattant les sucs avec une cuillère en bois."
  - "Ajouter la crème et laisser réduire 3 minutes à petits bouillons jusqu'à ce que la sauce nappe la cuillère. Rectifier le sel."
  - "Remettre les steaks et leur jus dans la sauce 30 secondes, puis servir nappés de sauce."
---

À servir avec des frites ou des pommes de terre sautées.
