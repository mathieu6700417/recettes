titre: "Version classique"
reference: true
statut: relu-agent
portions: 30
temps: { preparation: 30, cuisson: 30 }
difficulte: moyen
ingredients:
  - { ingredient: eau, qte: 125, unite: ml, groupe: "Pâte" }
  - { ingredient: lait-entier, qte: 125, unite: ml, groupe: "Pâte" }
  - { ingredient: beurre, qte: 100, unite: g, groupe: "Pâte" }
  - { ingredient: sucre-en-poudre, qte: 1, unite: c. à café, groupe: "Pâte" }
  - { ingredient: sel, qte: 1, unite: "pincée", groupe: "Pâte" }
  - { ingredient: farine, qte: 150, unite: g, groupe: "Pâte" }
  - { ingredient: oeuf, qte: 4, unite: "", groupe: "Pâte" }
  - { ingredient: sucre-perle, qte: 60, unite: g, groupe: "Finition" }
etapes:
  - "Préchauffer le four à 200 °C. Porter à ébullition l'eau, le lait, le beurre en morceaux, le sucre et le sel."
  - "Hors du feu, verser la farine tamisée d'un coup et mélanger énergiquement à la spatule."
  - "Remettre sur feu moyen et dessécher la panade 1 à 2 minutes, jusqu'à ce qu'elle se détache de la casserole et forme une boule lisse."
  - "Transférer dans un bol et laisser tiédir 2 minutes. Incorporer les œufs un à un, en attendant que chacun soit absorbé. La pâte doit former un ruban lisse en V quand on soulève la spatule ; n'ajouter le dernier œuf que si elle reste trop ferme."
  - "À la poche munie d'une douille unie de 12 mm, pocher des boules d'environ 3 cm sur une plaque couverte de papier sulfurisé, en les espaçant de 4 cm."
  - "Aplatir le sommet des pointes avec un doigt humide, puis parsemer généreusement de sucre perlé."
  - "Enfourner à 200 °C pendant 10 minutes, puis baisser à 170 °C et poursuivre 20 minutes sans ouvrir la porte, jusqu'à ce que les chouquettes soient bien dorées et légères."
  - "Laisser refroidir sur grille. Déguster le jour même."
---

Les 30 portions correspondent au nombre de pièces.
