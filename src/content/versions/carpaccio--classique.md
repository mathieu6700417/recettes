---
preparation: carpaccio
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 25, cuisson: 0, repos: 30 }
difficulte: facile
ingredients:
  - { ingredient: filet-de-boeuf, qte: 400, unite: g, precision: "très frais, bien paré" }
  - { ingredient: huile-d-olive, qte: 4, unite: "c. à soupe" }
  - { ingredient: citron, qte: 1, unite: "", precision: "le jus" }
  - { ingredient: parmesan, qte: 60, unite: g, precision: "en copeaux" }
  - { ingredient: roquette, qte: 60, unite: g }
  - { ingredient: fleur-de-sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Parer le filet, l'envelopper dans du film et le placer 30 minutes au congélateur : il doit être ferme mais pas gelé."
  - "Le trancher en lamelles de 2 mm avec un couteau très aiguisé (ou une trancheuse)."
  - "Disposer les tranches sur quatre assiettes froides, entre deux feuilles de film si besoin, et les aplatir légèrement à la paume ou au rouleau pour les rendre translucides."
  - "Au moment de servir, répartir l'huile d'olive et le jus de citron sur la viande."
  - "Parsemer de fleur de sel, de poivre, de copeaux de parmesan et de roquette. Servir immédiatement."
---

Sécurité : viande crue. Acheter le filet le jour même chez un boucher de confiance, le garder sous 4 °C
et le consommer dans la journée.
