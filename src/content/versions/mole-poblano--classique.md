  - { ingredient: piment-ancho, qte: 3, unite: "", groupe: "Sauce", precision: "épépinés" }
  - { ingredient: piment-mulato, qte: 2, unite: "", groupe: "Sauce", precision: "épépinés" }
  - { ingredient: piment-pasilla, qte: 2, unite: "", groupe: "Sauce", precision: "épépinés" }
  - { ingredient: tomate, qte: 2, unite: "", groupe: "Sauce" }
  - { ingredient: oignon, qte: 1, unite: "", groupe: "Sauce" }
  - { ingredient: ail, qte: 3, unite: gousse, groupe: "Sauce" }
  - { ingredient: amande, qte: 40, unite: g, groupe: "Sauce" }
  - { ingredient: cacahuete, qte: 40, unite: g, groupe: "Sauce" }
  - { ingredient: graine-de-sesame, qte: 2, unite: "c. à soupe", groupe: "Sauce" }
  - { ingredient: raisin-sec, qte: 40, unite: g, groupe: "Sauce" }
  - { ingredient: tortilla-de-mais, qte: 1, unite: "", groupe: "Sauce", precision: "grillée, pour lier" }
  - { ingredient: chocolat-noir, qte: 40, unite: g, groupe: "Sauce" }
  - { ingredient: cannelle, qte: 1, unite: "c. à café", groupe: "Sauce", precision: "moulue" }
  - { ingredient: clou-de-girofle, qte: 2, unite: "", groupe: "Sauce" }
  - { ingredient: bouillon-de-volaille, qte: 1, unite: l }
  - { ingredient: huile-neutre, qte: 4, unite: "c. à soupe" }
  - { ingredient: sel, qte: null, unite: "" }
etapes:
  - "Pocher la dinde 50 minutes dans le bouillon de volaille frémissant avec un peu de sel. Réserver la dinde et filtrer le bouillon."
  - "Griller les piments à sec dans une poêle 20 secondes par face, sans les brûler. Les réhydrater 20 minutes dans de l'eau chaude."
  - "Dans 2 c. à soupe d'huile, faire revenir séparément oignon, ail, tomates, puis amandes, cacahuètes, sésame (en garder 1 c. à café pour servir), raisins secs et tortilla, 3 à 5 minutes chacun."
  - "Mixer finement piments égouttés, ingrédients revenus, cannelle, girofle et 25 cl de bouillon, en rajoutant du liquide si nécessaire."
  - "Chauffer le reste d'huile dans une cocotte, y verser la purée en remuant. Cuire 10 minutes à feu moyen, puis ajouter le chocolat et 30 cl de bouillon."
  - "Mijoter 30 minutes à feu doux, couvert à demi, jusqu'à ce que la sauce nappe la cuillère. Saler."
  - "Ajouter la dinde, réchauffer 15 minutes. Servir avec du riz et des tortillas, parsemé de sésame."
---

Pour un mole plus léger, remplacer la dinde par du poulet (cuisses, 30 minutes de pochage).
