titre: Mousseline classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 10, cuisson: 0 }
difficulte: moyen
ingredients:
  - { preparation: hollandaise, qte: 200, unite: g, precision: "tiède" }
  - { ingredient: creme-liquide, qte: 10, unite: cl, precision: "bien froide" }
  - { ingredient: sel, qte: 1, unite: pincée }
etapes:
  - "Préparer la hollandaise selon sa recette et la garder tiède, à 50-55 °C."
  - "Fouetter la crème bien froide jusqu'à ce qu'elle forme une chantilly souple, sans la serrer."
  - "Incorporer délicatement la crème à la hollandaise, en 2 fois, avec une spatule en soulevant la masse."
  - "Rectifier l'assaisonnement, servir immédiatement."
---

La crème doit être fouettée mousseuse et non ferme, sinon elle fait grainer la sauce. Une mousseline
trop chaude se détend : la crème s'incorpore sur une hollandaise à peine tiède. Rattrapage : comme pour la hollandaise,
repartir d'une cuillère d'eau tiède fouettée.
