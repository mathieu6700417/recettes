difficulte: facile
ingredients:
  - { preparation: compotee-d-oignons, qte: 350, unite: g, groupe: "Soupe" }
  - { preparation: fond-brun, qte: 1, unite: l, groupe: "Soupe" }
  - { ingredient: vin-blanc, qte: 15, unite: cl, precision: "sec", groupe: "Soupe" }
  - { ingredient: farine, qte: 1, unite: c. à soupe, groupe: "Soupe" }
  - { ingredient: thym, qte: 2, unite: branche, groupe: "Soupe" }
  - { ingredient: laurier, qte: 1, unite: "", groupe: "Soupe" }
  - { ingredient: sel, qte: null, unite: "", groupe: "Soupe" }
  - { ingredient: poivre, qte: null, unite: "", groupe: "Soupe" }
  - { ingredient: pain-rassis, qte: 8, unite: tranche, precision: "fines, grillées", groupe: "Gratinée" }
  - { ingredient: gruyere, qte: 150, unite: g, precision: "râpé", groupe: "Gratinée" }
etapes:
  - "Préparer à l'avance la compotée d'oignons et le fond brun (voir leurs recettes). Prévoir environ 1 kg d'oignons pour 350 g de compotée."
  - "Dans une grande casserole, réchauffer la compotée à feu moyen. Saupoudrer de farine et remuer 1 minute."
  - "Verser le vin blanc et laisser réduire de moitié en grattant le fond de la casserole."
  - "Ajouter le fond brun chaud, le thym et le laurier. Porter à frémissement et laisser mijoter 20 minutes à feu doux, à couvert."
  - "Retirer le thym et le laurier, saler et poivrer."
  - "Préchauffer le gril du four. Griller les tranches de pain."
  - "Verser la soupe dans 4 bols allant au four, poser 2 tranches de pain dans chacun et couvrir de gruyère."
  - "Gratiner 5 à 8 minutes sous le gril, jusqu'à ce que le fromage soit fondu et bien doré. Servir aussitôt, les bols sont brûlants."
---

Le temps de cuisson ne compte que l'assemblage, le mijotage et le gratin : la compotée et le fond brun sont des préparations à part, à faire avant. Un peu de cognac ajouté avec le vin blanc est un classique, mais facultatif.
