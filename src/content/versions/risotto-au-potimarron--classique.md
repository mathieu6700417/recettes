---
preparation: risotto-au-potimarron
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 25 }
difficulte: moyen
ingredients:
  - { ingredient: riz-carnaroli, qte: 320, unite: g }
  - { preparation: fond-de-legumes, qte: 1.2, unite: l, precision: "maintenu frémissant" }
  - { ingredient: potimarron, qte: 400, unite: g, precision: "non épluché, en dés de 1 cm" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "petit, finement haché" }
  - { ingredient: beurre, qte: 80, unite: g, precision: "dont 40 g froid, en dés, pour la mantecatura" }
  - { ingredient: vin-blanc, qte: 100, unite: ml, precision: "sec" }
  - { ingredient: parmesan, qte: 60, unite: g, precision: "fraîchement râpé" }
  - { ingredient: sauge, qte: 6, unite: feuille, precision: "ciselées, facultatif" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Garder le fond de légumes à frémissement dans une casserole à côté."
  - "Faire fondre 40 g de beurre à feu moyen dans une large casserole à fond épais. Y faire fondre l'oignon 5 minutes, sans coloration."
  - "Ajouter le riz et le nacrer 2 minutes en remuant, jusqu'à ce que les grains soient chauds et translucides sur les bords."
  - "Verser le vin blanc et laisser évaporer complètement en remuant, environ 1 minute."
  - "Mouiller d'une louche de fond chaud. Remuer jusqu'à absorption presque totale, puis ajouter la louche suivante. Poursuivre ainsi à feu moyen."
  - "Après environ 8 minutes, ajouter les dés de potimarron et continuer à mouiller louche par louche, 8 à 10 minutes de plus. Saler légèrement en fin de cuisson."
  - "Quand le riz est tendre à cœur mais encore ferme, et le risotto fluide, retirer du feu."
  - "Mantecatura : ajouter hors du feu les 40 g de beurre froid en dés et le parmesan. Remuer vigoureusement, couvrir et laisser reposer 2 minutes. Parsemer de sauge et de poivre, servir aussitôt dans des assiettes creuses."
---

Pour un risotto plus crémeux, écraser quelques dés de potimarron contre la paroi de la casserole en fin de cuisson.
