statut: relu-agent
portions: 6
temps: { preparation: 45, cuisson: 30 }
difficulte: moyen
ingredients:
  - { ingredient: eau, qte: 125, unite: ml, groupe: "Choux" }
  - { ingredient: lait-entier, qte: 125, unite: ml, groupe: "Choux" }
  - { ingredient: beurre, qte: 100, unite: g, groupe: "Choux" }
  - { ingredient: sucre-en-poudre, qte: 1, unite: c. à café, groupe: "Choux" }
  - { ingredient: sel, qte: 1, unite: "pincée", groupe: "Choux" }
  - { ingredient: farine, qte: 150, unite: g, groupe: "Choux" }
  - { ingredient: oeuf, qte: 4, unite: "", groupe: "Choux" }
  - { ingredient: glace-a-la-vanille, qte: 75, unite: cl, groupe: "Garniture" }
  - { ingredient: chocolat-noir, qte: 200, unite: g, groupe: "Sauce" }
  - { ingredient: creme-liquide, qte: 200, unite: ml, groupe: "Sauce" }
  - { ingredient: amande-effilee, qte: 30, unite: g, precision: "grillées", groupe: "Finition" }
etapes:
  - "Porter à ébullition l'eau, le lait, le beurre, le sucre et le sel, ajouter la farine d'un coup, dessécher 1 à 2 minutes, puis incorporer les œufs un à un. Pocher des boules de 4 cm sur une plaque couverte de papier sulfurisé."
  - "Cuire à 200 °C pendant 10 minutes, puis à 170 °C pendant 20 minutes sans ouvrir la porte. Laisser refroidir sur grille."
  - "Sauce : porter la crème à frémissement, la verser sur le chocolat haché, attendre 1 minute puis mélanger jusqu'à obtenir une sauce lisse. Garder au chaud."
  - "Couper un chapeau au sommet de chaque chou, garnir d'une boule de glace vanille et refermer. Placer les choux au congélateur 10 minutes pour raffermir la glace."
  - "Dresser 4 choux par assiette, napper de sauce chocolat chaude au dernier moment et parsemer d'amandes."
---

Les 6 portions comptent 4 choux chacune, soit 24 pièces.
