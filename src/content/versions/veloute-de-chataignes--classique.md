---
preparation: veloute-de-chataignes
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 15, cuisson: 30 }
difficulte: facile
ingredients:
  - { ingredient: chataigne, qte: 500, unite: g, precision: "cuites et épluchées, sous vide" }
  - { ingredient: oignon, qte: 1, unite: "", precision: "émincé" }
  - { ingredient: celeri-branche, qte: 1, unite: branche, precision: "en petits dés" }
  - { ingredient: beurre, qte: 20, unite: g }
  - { preparation: fond-de-legumes, qte: 0.75, unite: l, precision: "chaud" }
  - { ingredient: creme-liquide, qte: 10, unite: cl }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Faire fondre le beurre dans une casserole à feu moyen. Y faire suer l'oignon et le céleri 6 minutes, sans coloration."
  - "Ajouter les châtaignes et remuer 2 minutes pour les enrober."
  - "Verser le fond de légumes chaud : il doit couvrir les châtaignes. Porter à frémissement."
  - "Couvrir et laisser mijoter à feu doux 20 minutes, jusqu'à ce que les châtaignes s'écrasent sans résistance."
  - "Mixer finement au mixeur plongeant pendant 3 minutes, jusqu'à obtenir une texture très lisse."
  - "Ajouter la crème et la muscade, réchauffer sans bouillir. Allonger d'un peu de fond chaud si le velouté est trop épais. Saler et poivrer."
  - "Servir aussitôt, avec un filet de crème et quelques éclats de châtaigne poêlés si l'on veut."
---

Le velouté se garde 3 jours au réfrigérateur ; il épaissit en refroidissant et se détend avec un peu de fond ou de lait.
