  preparation: 15
  cuisson: 45
difficulte: facile
ingredients:
  - { ingredient: eau, qte: 2, unite: l, precision: froide }
  - { ingredient: oignon, qte: 2, unite: "" }
  - { ingredient: carotte, qte: 3, unite: "" }
  - { ingredient: poireau, qte: 1, unite: "" }
  - { ingredient: celeri-branche, qte: 2, unite: branche }
  - { ingredient: ail, qte: 1, unite: gousse, precision: facultatif }
  - { ingredient: persil, qte: 3, unite: branche, groupe: Bouquet garni }
  - { ingredient: thym, qte: 2, unite: branche, groupe: Bouquet garni }
  - { ingredient: laurier, qte: 1, unite: "", groupe: Bouquet garni }
  - { ingredient: poivre, qte: null, unite: "", precision: 6 grains }
etapes:
  - Éplucher les légumes et les couper en gros morceaux.
  - Les mettre dans une marmite avec le bouquet garni, le poivre et l'ail écrasé, couvrir de 2 l d'eau froide.
  - Porter doucement à frémissement, écumer, puis cuire 45 minutes à frémissement, à couvert entrouvert.
  - Filtrer au chinois sans presser. Refroidir vite, réserver au froid 3 jours ou congeler.
---

Rendement : environ 1,5 l de fond (portions de 25 cl). Un fond de légumes ne se sale presque pas : le sel se règle dans le plat final. Pour un goût plus rond, faire suer les oignons et les carottes 5 minutes dans un peu d'huile avant de mouiller.
