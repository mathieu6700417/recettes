---
preparation: zuppa-di-cozze
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 25, cuisson: 25 }
difficulte: facile
ingredients:
  - { ingredient: moule, qte: 2, unite: kg, precision: "grattées et rincées" }
  - { ingredient: huile-d-olive, qte: 5, unite: c. à soupe }
  - { ingredient: ail, qte: 4, unite: gousse, precision: "dont 1 pour frotter le pain" }
  - { ingredient: piment-en-flocons, qte: 1, unite: pincée }
  - { ingredient: vin-blanc, qte: 15, unite: cl, precision: "sec" }
  - { ingredient: tomate-pelee, qte: 400, unite: g, precision: "écrasées" }
  - { ingredient: persil-plat, qte: 1, unite: botte, precision: "haché" }
  - { ingredient: pain, qte: 8, unite: tranche, precision: "de campagne" }
  - { ingredient: poivre, qte: null, unite: "" }
  - { ingredient: sel, qte: null, unite: "", precision: "seulement si nécessaire" }
etapes:
  - "Gratter les moules, retirer les byssus et les rincer à l'eau froide. Jeter celles qui sont cassées ou qui restent ouvertes quand on les tapote."
  - "Dans une grande cocotte, chauffer 4 cuillerées d'huile à feu moyen avec 3 gousses d'ail écrasées et le piment. Laisser blondir 2 minutes."
  - "Verser le vin blanc, laisser bouillir 1 minute, puis ajouter les tomates et la moitié du persil. Laisser mijoter 10 minutes à découvert, jusqu'à ce que la sauce épaississe."
  - "Ajouter les moules, couvrir et cuire à feu vif 5 à 6 minutes en secouant la cocotte, jusqu'à ce qu'elles soient toutes ouvertes. Jeter celles qui restent fermées."
  - "Pendant ce temps, griller les tranches de pain, les frotter avec la dernière gousse d'ail et les arroser du reste d'huile."
  - "Poivrer, goûter le bouillon et saler seulement si nécessaire. Poser le pain au fond d'assiettes creuses, répartir les moules et la sauce par-dessus, parsemer du reste de persil et servir aussitôt."
---

Prévoir un bol pour les coquilles vides et du pain en plus pour saucer.
