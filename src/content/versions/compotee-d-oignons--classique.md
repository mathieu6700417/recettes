---
preparation: compotee-d-oignons
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps:
  preparation: 15
  cuisson: 50
difficulte: facile
ingredients:
  - { ingredient: oignon-jaune, qte: 1, unite: kg, precision: émincés finement }
  - { ingredient: beurre, qte: 40, unite: g }
  - { ingredient: sel, qte: 1, unite: c. à café }
  - { ingredient: sucre, qte: 1, unite: c. à café, precision: facultatif }
  - { ingredient: vinaigre-de-vin, qte: 5, unite: cl, precision: "facultatif, pour déglacer" }
etapes:
  - Éplucher et émincer finement les oignons.
  - Faire fondre le beurre dans une grande sauteuse, y jeter les oignons avec le sel, couvrir et cuire 10 minutes à feu moyen pour qu'ils rendent leur eau.
  - Découvrir, baisser à feu doux et cuire 35 à 45 minutes en remuant de temps en temps, jusqu'à une belle couleur dorée. Ajouter une cuillère d'eau si ça attache.
  - En fin de cuisson, ajouter le sucre puis déglacer avec le vinaigre, laisser s'évaporer. Rectifier le sel.
---

Rendement : environ 300 à 350 g de compotée. On peut remplacer le beurre par de l'huile d'olive. Elle se conserve 5 jours au froid, ou se congèle en portions.
