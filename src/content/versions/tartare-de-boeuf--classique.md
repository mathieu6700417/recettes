ingredients:

  - { ingredient: jaune-d-oeuf, qte: 2, unite: "", precision: "extra-frais" }
  - { ingredient: echalote, qte: 2, unite: "", precision: "ciselées finement" }
  - { ingredient: capre, qte: 2, unite: "c. à soupe", precision: "égouttées et hachées" }
  - { ingredient: cornichon, qte: 4, unite: "", precision: "hachés" }
  - { ingredient: persil-plat, qte: 2, unite: "c. à soupe", precision: "ciselé" }
  - { ingredient: moutarde, qte: 1, unite: "c. à soupe" }
  - { ingredient: sauce-worcestershire, qte: 1, unite: "c. à café" }
  - { ingredient: sauce-piquante, qte: 1, unite: "c. à café", precision: "à ajuster" }
  - { ingredient: huile-neutre, qte: 1, unite: "c. à soupe" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Placer la viande 20 minutes au congélateur pour la raffermir, ce qui facilite la découpe. Elle doit rester très froide (moins de 4 °C) jusqu'au service."
  - "Parer la viande : retirer nerfs et graisse. La couper en tranches de 3 mm, puis en bâtonnets, puis en petits dés de 3 mm, au couteau bien aiguisé."
  - "Dans un saladier froid, mélanger la moutarde, le Worcestershire, la sauce piquante, l'huile et les jaunes d'œufs."
  - "Ajouter l'échalote, les câpres, les cornichons et le persil, puis la viande. Mélanger délicatement à la fourchette."
  - "Saler et poivrer, goûter, rectifier le piquant."
  - "Dresser à l'emporte-pièce sur des assiettes froides et servir aussitôt, avec des frites ou une salade verte."
---

Sécurité : viande et œufs crus. Utiliser des produits très frais achetés le jour même, ne pas conserver
les restes, et éviter ce plat pour les jeunes enfants, les femmes enceintes et les personnes fragiles.
