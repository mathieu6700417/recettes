---
preparation: soupe-poireaux-pommes-de-terre
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 30 }
difficulte: facile
ingredients:
  - { ingredient: poireau, qte: 600, unite: g, precision: "blanc et vert tendre, lavés et émincés" }
  - { ingredient: pomme-de-terre, qte: 400, unite: g, precision: "épluchées, en dés de 2 cm" }
  - { ingredient: beurre, qte: 30, unite: g }
  - { preparation: fond-de-legumes, qte: 1, unite: l, precision: "chaud" }
  - { ingredient: creme-liquide, qte: 10, unite: cl }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Fendre les poireaux en deux dans la longueur, les laver sous l'eau courante en écartant les feuilles, puis les émincer en tronçons de 1 cm."
  - "Faire fondre le beurre dans une grande casserole à feu moyen. Y faire suer les poireaux 8 minutes en remuant, sans coloration."
  - "Ajouter les pommes de terre, remuer 1 minute, puis verser le fond de légumes chaud. Porter à frémissement."
  - "Couvrir et laisser mijoter à feu doux 20 minutes, jusqu'à ce que les pommes de terre s'écrasent à la fourchette."
  - "Mixer au mixeur plongeant, finement ou en laissant quelques morceaux selon le goût. Allonger d'un peu de fond ou d'eau chaude si la soupe est trop épaisse."
  - "Ajouter la crème, réchauffer sans bouillir, saler et poivrer."
  - "Servir bien chaud, avec une mouture de poivre et, si l'on veut, des croûtons."
---

La soupe se garde 3 jours au réfrigérateur et se congèle bien avant l'ajout de la crème.
