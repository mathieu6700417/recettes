preparation: gravlax
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 0, repos: 2880 }
difficulte: facile
ingredients:
  - { ingredient: saumon, qte: 600, unite: g, precision: "filet avec la peau, sans arêtes, congelé 24 h à −20 °C puis décongelé" }
  - { ingredient: gros-sel, qte: 30, unite: g }
  - { ingredient: sucre, qte: 30, unite: g }
  - { ingredient: aneth, qte: 1, unite: botte, precision: "ciselé grossièrement" }
  - { ingredient: poivre, qte: 1, unite: "c. à café", precision: "concassé" }
etapes:
  - "Congeler le saumon 24 h à −20 °C, puis le décongeler au réfrigérateur. Vérifier qu'il ne reste aucune arête."
  - "Mélanger le sel, le sucre et le poivre."
  - "Dans un plat, étaler la moitié de l'aneth, poser le filet côté peau dessous, frotter la chair avec le mélange sel-sucre puis recouvrir du reste d'aneth."
  - "Couvrir de film, poser une planche et un poids de 1 kg environ."
  - "Réfrigérer à moins de 4 °C pendant 48 h, en retournant le poisson toutes les 12 heures et en l'arrosant du jus rendu."
  - "Rincer rapidement le saumon, le sécher, puis le trancher finement en biais, de la queue vers la tête, sans la peau."
  - "Servir avec du pain de seigle, de la crème aigre ou de la moutarde à l'aneth."
---

Se conserve 3 à 4 jours au réfrigérateur. Sécurité : poisson cru, la congélation préalable est
indispensable ; éviter pour les femmes enceintes et les personnes fragiles.
