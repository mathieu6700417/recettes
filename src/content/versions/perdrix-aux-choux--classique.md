---
preparation: perdrix-aux-choux
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 30, cuisson: 120 }
difficulte: moyen
ingredients:
  - { ingredient: perdrix, qte: 2, unite: "", precision: "adultes, bridées" }
  - { ingredient: chou-vert, qte: 1, unite: "", precision: "environ 1,2 kg, en quartiers, sans le trognon" }
  - { ingredient: poitrine-fumee, qte: 200, unite: g, precision: "en gros lardons" }
  - { ingredient: saucisse-fumee, qte: 1, unite: "", precision: "environ 300 g" }
  - { ingredient: carotte, qte: 2, unite: "", precision: "en rondelles" }
  - { ingredient: oignon, qte: 2, unite: "", precision: "dont un piqué d'un clou de girofle" }
  - { ingredient: clou-de-girofle, qte: 1, unite: "" }
  - { ingredient: thym, qte: 2, unite: branche, precision: "bouquet garni" }
  - { ingredient: laurier, qte: 1, unite: "", precision: "bouquet garni" }
  - { ingredient: persil, qte: 3, unite: branche, precision: "bouquet garni" }
  - { ingredient: bouillon-de-volaille, qte: 40, unite: cl }
  - { ingredient: beurre, qte: 30, unite: g }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Blanchir les quartiers de chou 5 minutes à l'eau bouillante, les égoutter, les presser et les hacher grossièrement."
  - "Blanchir les lardons 3 minutes, puis les égoutter."
  - "Faire fondre le beurre dans une cocotte et y dorer les perdrix sur toutes leurs faces, 10 minutes. Les retirer."
  - "Dans la même cocotte, faire revenir les lardons, les oignons et les carottes 5 minutes."
  - "Étaler la moitié du chou dans la cocotte, saler légèrement et poivrer. Poser les perdrix et la saucisse, ajouter le bouquet garni, puis couvrir du reste du chou."
  - "Mouiller avec le bouillon, couvrir et cuire 1 h 30 à feu très doux, ou au four à 160 °C."
  - "Retirer la saucisse au bout de 45 minutes, la trancher et la remettre dans la cocotte pour la fin de la cuisson."
  - "Disposer le chou dans un plat, les perdrix découpées et la saucisse par-dessus, et napper de jus."
---

Utiliser de préférence des perdrix adultes ; si elles sont jeunes, réduire la cuisson à 45 minutes.
