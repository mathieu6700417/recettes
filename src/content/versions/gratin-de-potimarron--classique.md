---
preparation: gratin-de-potimarron
titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 25, cuisson: 40 }
difficulte: facile
ingredients:
  - { ingredient: potimarron, qte: 1, unite: kg, precision: "non épluché, en tranches de 1 cm" }
  - { preparation: bechamel, qte: 0.5, unite: l, precision: "fluide, bien relevée de muscade" , groupe: "Sauce" }
  - { ingredient: gruyere, qte: 100, unite: g, precision: "râpé (ou comté)", groupe: "Sauce" }
  - { ingredient: beurre, qte: 15, unite: g, precision: "pour le plat" }
  - { ingredient: noix-de-muscade, qte: 1, unite: pincée, precision: "râpée" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Préchauffer le four à 200 °C. Beurrer un plat à gratin."
  - "Laver le potimarron, le couper en deux, retirer les graines et les filaments. Le couper en tranches de 1 cm sans l'éplucher."
  - "Cuire les tranches à la vapeur 10 à 12 minutes, jusqu'à ce que la pointe d'un couteau les traverse avec un peu de résistance. Les égoutter et les éponger."
  - "Préparer 0,5 l de béchamel fluide selon la recette de base (25 g de beurre, 25 g de farine), puis l'assaisonner de sel, de poivre et de muscade. Y mélanger la moitié du gruyère."
  - "Ranger les tranches de potimarron dans le plat en les faisant se chevaucher. Napper de béchamel et parsemer du reste de fromage."
  - "Enfourner 25 à 30 minutes sur la grille du milieu, puis 5 minutes sous le gril, jusqu'à ce que la surface soit dorée et bouillonnante."
  - "Laisser reposer 5 minutes avant de servir."
---

Le gratin se prépare à l'avance : prévoir 10 minutes de cuisson en plus s'il sort du réfrigérateur.
