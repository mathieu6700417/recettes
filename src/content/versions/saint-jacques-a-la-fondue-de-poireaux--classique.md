titre: Version classique
reference: true
statut: relu-agent
portions: 4
temps: { preparation: 20, cuisson: 25 }
difficulte: moyen
ingredients:
  - { ingredient: saint-jacques, qte: 12, unite: "", precision: "noix fraîches, sans corail" }
  - { ingredient: poireau, qte: 4, unite: "", precision: "blancs et vert tendre, en fines rondelles", groupe: "Fondue" }
  - { ingredient: beurre, qte: 60, unite: g, precision: "dont 30 g pour la fondue", groupe: "Fondue" }
  - { ingredient: creme-liquide, qte: 10, unite: cl, groupe: "Fondue" }
  - { ingredient: vin-blanc, qte: 5, unite: cl, precision: "sec", groupe: "Fondue" }
  - { ingredient: huile-neutre, qte: 1, unite: c. à soupe }
  - { ingredient: persil-plat, qte: 2, unite: branche, precision: "ciselé" }
  - { ingredient: sel, qte: null, unite: "" }
  - { ingredient: poivre, qte: null, unite: "" }
etapes:
  - "Laver soigneusement les poireaux et les émincer en fines rondelles."
  - "Faire fondre 30 g de beurre dans une sauteuse, y ajouter les poireaux et une pincée de sel. Couvrir et cuire à feu doux 15 minutes en remuant, sans coloration."
  - "Verser le vin blanc, laisser évaporer 1 minute, puis ajouter la crème et cuire 5 minutes à découvert, jusqu'à ce que la fondue soit nappante. Rectifier l'assaisonnement et garder au chaud."
  - "Sécher les noix de Saint-Jacques sur du papier absorbant et les saler."
  - "Chauffer l'huile dans une poêle à feu vif, y saisir les noix 1 min 30 à 2 minutes par face, en ajoutant le reste du beurre en fin de cuisson."
  - "Répartir la fondue dans les assiettes, poser les noix par-dessus, poivrer et parsemer de persil. Servir aussitôt."
---

Les noix doivent rester légèrement nacrées au centre : une cuisson trop longue les rend caoutchouteuses.
